# 首轮A上升：同配对分解、几何与监督覆盖

2026-09-06 05:03 Asia/Shanghai。用户要求解释A上升，本文分析已完成的原生
固定256评估，重点是双方均通过验证的37对。没有新增模型采样、物理打分或训练；
全部来自现有评估、原始标签和已保存的token事件。

## 1. A上升不是一个不可分解的数字

对同一组37对，逐样本验证

\[
\Delta A=\Delta e_0-\Delta e_R.
\]

| 同配对平均差 | eV/atom | meV/atom |
|---|---:|---:|
| 原始能量 delta e0 | +0.0700202633 | +70.0203 |
| 终态能量 delta eR = delta B | -0.0557481824 | -55.7482 |
| 原生—终态差 delta A | +0.1257684456 | +125.7684 |

约56meV的A增加在代数上来自更低的终态，另约70meV来自更高的原始能量。
因此A和B并不是独立指标：终态更低而原生能量不跟着降低，能差就会增大。
这解释统计构成，不等于已经证明两个独立的因果机制。

不能拿253个原始能量配对的+42meV代入这个分解：253和37是不同条件集合。

## 2. 正负大变化抵消，不能把均值理解成均匀退步

- A上升超过1meV：17对；下降超过1meV：12对；变化在±1meV内：8对。
- A差的中位数约0；37对中有6对最终token完全一样。
- 正变化累计+51.040908，负变化累计-46.387475，净和+4.653432；除以37才是
  平均+0.125768。这里的累计值只是诊断贡献，单位仍为各配对每原子能差之和。
- 最大一例占全部正变化18.57%，前三例占47.87%；不是一个异常值完全解释结果，
  但均值对少数大变化较敏感。所有样本始终保留在原指标中。

## 3. 大幅上升的具体样本显示过密几何

以下按A上升排序，仅用于追因，不作为新评价子集。

| 样本/组成（原胞计数） | delta A eV/atom | 原生能量 参考→方法 | 终态能量 参考→方法 | 体积/原子 Å³ 参考→方法 | 最小周期距离 Å 参考→方法 |
|---|---:|---:|---:|---:|---:|
| 245 / In6Yb2 | +9.4758 | +0.0024 → +9.4845 | -2.7885 → -2.7822 | 46.4117 → 12.7358 | 2.1242 → 1.4250 |
| 58 / Sn5U | +8.8325 | -4.3481 → +4.2021 | -4.9509 → -5.2332 | 32.5799 → 17.1473 | 2.7500 → 1.5439 |
| 47 / F6InK2Y | +6.1248 | -2.7313 → +3.3871 | -5.5944 → -5.6008 | 15.9659 → 8.6655 | 1.6000 → 1.0250 |
| 74 / CaCl2 | +5.9044 | +0.1975 → +6.0449 | -4.6234 → -4.6804 | 17.6065 → 11.7377 | 1.9646 → 1.4472 |

前三例的A增加主要来自原生能量抬升，终态能量变化小得多。原始最大力也分别
从14.58到26.77、0.00027到34.12、25.12到55.50eV/Å。
这支持明确的几何层解释：**部分提议的晶胞更紧、原子更近，公共弛豫需要消除
更多原生非平衡。**其中In6Yb2几乎没有终态能量收益，不能把它解释成主动选择
更深盆地的必要代价。F6NdRb3另有同体积、最小距离1.5902降到0.6100的情况，
说明坐标排布也能单独增加负担，不能只看体积。

这些是当前CHGNet与公共R下的观测，不构成势模型之外的物理真实性证明。

## 4. 已经能定位的阶段与不能认定的因果

从完整token事件重建：37对中仅3对构造终点完全相同；上述前三例在进入协同
修订之前，构造就已分别相差7、5、9个token，包含2、2、2个晶格token。
它们随后都接受了协同事务，也经过闭合。

因此不能把全部A恶化都归因于一次协同事务。当前比较的参考使用39700 closure
基座和旧修订流程，新方法包含39853状态warmup、新事务以及39892路径后训练。
它是完整方法比较，缺少隔离这些因素的对照；本次诊断不会伪装成单模块因果实验。

现有推理验收要求组成、token类型、非退化晶格及0.5Å等几何底线，不读取能量。
过密但仍满足这些底线的结构可以合法通过。**合法动作范围比低能近平衡范围大**，
而当前学习尚未稳定缩小二者差距。这不是发现了阈值实现错误，也不构成临时改阈值
或加入推理MLIP的理由。

## 5. 监督范围与强度的实际限制

将37个组成与本轮1024个能量训练条件按元素计数匹配，完全计数和约化比例两种
口径均无重合。也就是说，这37对没有同组成的K4能量教师，本次在检验跨组成迁移。
这不代表完整MP20 warmup/CE或底座从未见过这些组成，不能作那种扩大推断。

首轮能量池还有两项已知限制：

- 1024组中526组有可用验证路径，只有273组有至少两条路径可供能量比较；
  253个单路径组主要提供验证路径的似然监督。
- 平均TV(q,u)=0.025613，重分配幅度较弱；教师对A/B的均值收益各约22.47meV/atom。
  训练大部分质量仍接近验证候选的均匀参考，不能解释为强而全面的低能监督。

**当前最有根据的工作假设**是：稀疏且较弱的能量偏好，在跨组成泛化和较大的合法
几何动作空间中，尚未学会稳定避免过密高能提议。证据支持这个方向，但没有证明
唯一原因是数据不足、训练次数不足或某一模块。不能把K8一定能修好当成既定事实。

K8会增加同一1024组成内的候选和可比较路径，最后训练会增加真实状态覆盖；
它不会增加组成覆盖。待完整标签齐备，核对验证率、每组对比和权重集中度后，
按已登记方案续训；这些开发诊断不用于换组、筛失败或挑checkpoint。
