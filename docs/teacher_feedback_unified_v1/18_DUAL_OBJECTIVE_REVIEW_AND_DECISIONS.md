## 4. 双目标求解的数学复核

设 `r_cj=(A_cj-mean_u A_c, eR_cj-mean_u eR_c)`，`s=0.1 eV/atom`，`z=r/s`，各验证条件等权。第一步最大化共同改善 ρ，约束两项 `mean_w z <= -ρ`、平均 KL ≤κ=0.2。

其二维凸对偶可写为

\[
\rho_{\max}=\min_{0\le a\le1,\eta\ge0}
\left[\eta\kappa+
\frac{\eta}{C}\sum_c\log\sum_j u_{cj}
\exp\left(-\frac{a z_{A,cj}+(1-a)z_{B,cj}}{\eta}\right)\right].
\]

`η=0` 用连续极限处理。第二步取 `d=sρ_max/2`，最小化 KL 并要求两项平均差 ≤−d；两维 λ 对偶、梯度和协方差 Hessian 已写入主计划。

半程目标的可行性不是猜测：若第一步可行解为 w，则 `(u+w)/2` 已达到一半共同收益；由 KL 的凸性，其平均 KL≤0.1。第二步最小 KL 解不会更大，因此无需再叠加同类门禁。

两个重要反例：

1. 全部候选 A/B 相同：任何重加权都没有收益，返回参考。
2. 候选 `(A,B)=(0,1),(1,0)`：所有混合的 `E[A]+E[B]=1`，不可能同时小于参考的 `(0.5,0.5)`。不能用两个正 λ 冒充双降。

合成数值检查（非晶体、非正式 solver 验收）：两组四候选中，找到平均 KL≈0.1968 的可行权重，使 A 从0.34375降至0.30025，B从0.19750降至0.15667。它只确认存在有双降的例子，与真实 1024 组 headroom 无关。

经验池上的双降是构造性质，不是独立发现；有限数据、LoRA 拟合和 CE anchor 不保证学生继承它。双均值下降也不构成能量分布的一阶随机占优，旧单 β 理想后验的阈值单调性不能直接搬到本双目标经验方法。

## 5. 三组合并工程验收，批准后才运行

### E1. 状态注入、梯度、模式、位置和吞吐

- 现有 `TransactionLogitTransform.prepare` 发生在 forward 之后，不能用它假装输入状态已进入 DLM。新增显式 forward 输入包装。
- mixed-length 的 cell 相对位置1–6、XYZ相对位置`8+4i..10+4i` 按每行 prompt 起点处理，不碰 prompt/PAD。
- conditioner 输出和 logits 不 detach；仅旧整数快照/派生输入不要求梯度。状态生命周期必须覆盖 checkpoint backward。
- 路径 likelihood 关闭 dropout，但保留 autograd/checkpoint，避免旧 scorer 临时 eval/train 切换导致重计算语义不同。
- 只训练 LoRA A/B+conditioner；完整加载但冻结 embedding/head，包括 `modules_to_save` 副本。检查实际参数清单与 optimizer 参数。
- 零投影时同输入 logits 对照；短步后梯度、混精度、重计算、reload 对照，并记录实际四卡状态/秒和显存。

### E2. 联合事务与支持域

- 不顺序拼接旧 cell/site API 来冒充联合动作；它们的提前验收与局部回滚边界不正确。
- 联合动作允许未定活动坐标暂不参与旧位置碰撞拒绝；只检查已经能确定的几何，最后整体验收。
- 整体回滚包括 cell/活动XYZ/cache/lattice-version，非活动 token 和组成不变；旧态非法仍报失败。
- 用构造好的“单独改变被挡住、联合改变合法”例子验证真实作用，并验证非法联合动作完整恢复。
- N=1 自身周期像等支持缺口按共同 validator 处理，参考与新结果同口径报告，不改写历史结果。

### E3. 完整 attempted-trace 与训练权重

- 保留回滚前已经采样的 scalar；Z 未采样不补概率；确定性预填/回滚不额外乘概率。
- sampler与replay一致复现 schema、alias、几何支持、温度、逐分量条件状态。
- 旧日志丢失 rejected X/Y、旧 scorer 将 rejected cell 置负无穷，不能直接复用为完整路径。
- 旧 collator 的 `sample_weight ... or 1.0` 会抹掉零权重语义；新 trajectory loss 明确处理零权重/缺失，不使用该默认。
- 每条路径分层六状态使用正确 inclusion probability，不再除以路径长度；不同阶段均能收到终点价值。

这三组用于发现工程错误，不产生新的晶体方法臂；首128 train 标注用于协议检查，固定256用于整法首轮结算。没有任何一项已经因本次文档审查被标为测试通过。

## 6. 工程范围与算力审计

实现尽量收敛为四类可复用接口，不按每个 job 再造一套方法脚本：

| 接口 | 复用资产/最小变化 |
|---|---|
| Periodic state conditioning | 复用 tokenizer/数值几何；一个小 conditioner 与 DLM forward 包装 |
| Cooperative SPAD transaction | 复用 program/compiler/schema；一个独立 opt-in 联合事务，旧默认路径不变 |
| Trajectory recorder/replay/objective | 记录事件与实际子状态，通用零权重/HT/全路径评分；替换旧 K4 分类目标 |
| Terminal labels / reports | 扩充现有 CHGNet 标注的终点结构、力/应力、收敛和 A/B；共用评价缓存与报告 |

没有新 Llama 训练、没有新词表、没有连续残差回归、没有可微 CHGNet/弛豫反传、没有 PPO/critic 网络。

计算量审计接受工程 reviewer 的意见：98304 个路径状态不是“98k 个很轻的小头样本”；加 full MP20 warmup 和默认 CE anchor 是约150016状态/9376更新。输入梯度仍经过完整 DLM。参数轻量与计算轻量必须分开。

时间仅为条件预算：主计划现按首轮14–26h、含刷新和256结算24–48h预留；首个 E1 实测后修正。旧冲刺截止不自动延长，用户需要基于新预算决定是否执行。本轮没有消耗 A800 算力。

## 7. 论文口径修正

统一主线是：**科学支持的 Llama 程序 → 周期状态下可执行的 DLM 协同修订 → 同一程序的双目标物理学习。**不是新添一个与 LLM 无关的稳定性后处理器。

保留但不夸大：

- Llama 已学习的组成/程序资产保留；本轮冻结它，不声称其受双目标直接更新或在线掌控物理反馈。
- 非因果 DLM 保留未来结构修订早期 token，是机制的执行能力；不能据整法比较宣称任何 AR 方案理论上做不到。
- 共同评价下终态能量或 Stable 改善才支持盆地更好。SUN 可能只受输入 N/U 改变，不能单独证明盆地下降。
- A 是原生—弛豫终态能差，不等同于 force、stress 或优化步数。原生平衡精度与计算负担分别报告。
- 现有 SUN 的 N/U 在输入结构上计算、稳定性取公共弛豫能量；不称为已验证的非重复低能极小值集合。
- model494/tau800 是另列系统保底，不能替代原生学习证据。
