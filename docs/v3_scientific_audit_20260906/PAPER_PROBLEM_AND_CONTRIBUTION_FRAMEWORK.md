# 化学可达性与周期几何协同的 de novo 晶体生成

2026-09-06。约两页定位草稿；**主任务是自主生成组成与结构的 de novo 晶体生成，固定组成只作机制诊断。** 本轮故事依据限定为已核验接收的 NeurIPS 主会 FlowLLM、GenMS、CrysLLMGen，阅读位置见[顶会写法核读](TOPCONF_LANGUAGE_STORY_PATTERNS.md)。H-P33 尚无最终效果结论，本稿不改变实验合同。

## 统一问题：What / Why / How

**科学问题：在不给定目标化学式或参考结构时，如何让 LLM 的离散化学生成与 DLM 的周期几何建模协同，自主生成化学组成和晶体结构，并在相同完整生成预算下提高稳定、独特且新颖的晶体产率？** 研究范围是声明元素/价态支持内的无机晶体，不将 benchmark 稳定性等同真实可合成性。

**What——学习完整晶体的联合生成分布。** 系统自行选择 N、元素与计数 C，再产生晶格 L 和分数坐标 F；S/P 是内部软提示与程序。可用阶段式分解

`p(C,L,F) = sum_{S,P} q_phi(C,S,P) * p_theta(L,F | C,S,P)`

组织 LLM+DLM 系统。C 由生成器抽样，不能由测试晶体提供正确答案；几何后端使用 C 并不把整体任务变为 CSP。当前阶段式模型由冻结上游与几何后端实现，LLaDA 内 T/G 共享参数。这个因子分解不作为新定理，也不预设 S/P 已具有可识别的控制语义。

**Why——de novo 同时面对化学选择与周期结构的失配。** 组成合法不保证低 hull 结构存在，有限精度的结构文本也不保证几何可用。FlowLLM 与 CrysLLMGen 已将离散/连续互补作为主线；GenMS 已指出用户难以预先给出正确化学式。我们的具体切入点应是：把可完成的化学动作支持置于生成过程内，同时让 DLM 学习实际周期几何，检验两者是否改善完整发现产率。不能重新认领“首次混合 LLM 与 diffusion”或一般的语言→化学式→结构分工。[FlowLLM 主会论文](https://proceedings.neurips.cc/paper_files/paper/2024/file/51d317df78eded9eb3c9d3fb1091c279-Paper-Conference.pdf)、[GenMS 主会论文](https://proceedings.neurips.cc/paper_files/paper/2024/file/447d012bd95b6767a4bfdebf96cdfcc9-Paper-Conference.pdf)、[CrysLLMGen 主会论文](https://proceedings.neurips.cc/paper_files/paper/2025/file/f789a628fca473e922c806657512a20f-Paper-Conference.pdf)。

**How——两个互补机制，先以完整任务检验。** 化学端在可达动作支持内学习组成分布；几何端承接模型生成的组成与条件，学习周期结构。主实验从上游抽样开始，统计全部请求、全部候选和完整成本。随后分解组成/几何/精修结果，最后用固定 C/S/P 的配对实验解释收益来源；模块交互单列。候选假说是这两个环节的具体联结提高 de novo SUN，不能仅凭某个条件风险下降宣布成功。

## 两项互补的候选贡献

**贡献一：可达化学支持内的学习式语言模型提案。** C³FD 根据原子预算、电荷、family/arity 和有限氧化态见证计算可继续完成的动作支持；Typed Llama 对 species/count 联合动作学习归一化的 log-linear 残差，输出明确的硬组成及 S/P 接口。其职责是提案分布与化学约束，不能把下游几何成功全部归入此项。

- **需要的证据：** 完整 de novo 请求上的化学有效性、组成覆盖/重复、SUN 与成本，以及同一后端下 C³FD 与 Llama 残差的增量。语言预训练归因还需保留联合动作 head 的替代对照，排除仅由容量或 species/count 联合表达带来的收益；非零 KL 不够。
- **最近工作与新意边界：** FlowLLM-Types 已研究组成先验，GenMS 已用语言模型提出化学式。可争取的增量是可达 ledger 与学习式联合动作的具体结合及完整生成效用；普通 mask、残差或 PoE 名称不算创新。若 C³FD 属于既有组件，原有算法不能重复认领。常量目标与未证实的 S/P 作用，也不支持自由语言控制、物理最优规划或语言知识因果价值。[上游代码审计](C3FD_LLM_UPSTREAM_AUDIT.md)

**贡献二：面向模型自生组成的 DLM 周期几何生成。** 它与贡献一共同构成完整联合生成器，不能只用给定正确组成的任务证明。采用连续或离散路径由最终效果与机制证据决定。

| 路径 | 具体机制与可用贡献表述 | 必须补齐的归因证据 | 最近工作及不能算贡献的部分 |
|---|---|---|---|
| **H-G 有效** | 共享 LLaDA 的 T construction 与 G 几何学习；G 从先验出发，在完整 noisy L/F 上直接预测周期几何场，保持上游抽样得到的 N/E。候选增量是语言骨干中的共享符号/几何实现机制。 | 完整 de novo native/refined 结果；额外两 epoch 的预算对照；float/Q 与固定生成组成只作归因诊断。T、P 和预训练的价值按拟保留的主张分别验证。 | 最近是 FlowLLM/CrysLLMGen 的独立连续后端，及 GenMS 的分层生成；因此一般“语言＋连续生成”已被覆盖。实际共享学习和生成行为才是待验证差别；连续 diffusion、标准表示或梯度存在本身不算贡献。 |
| **回到离散路径** | 从修正口径后有效的 K4/K8 或更早路线出发，采用一个有实证增益的离散更新，提高模型自生组成上的结构生成；最终写清改变的状态、目标与采样分布。 | 主表仍评估联合 de novo 生成；固定化学 cohort 解释改进来自何处。若用 K 候选教师，区分候选质量与最终学生收益，计训练与推理成本。 | 三篇主会工作已经覆盖分层语言生成及后端优化；不能以换成 DLM 名称、增大 K、旧 best checkpoint 或普通 CE 改名声称新颖。新的离散机制尚未确定时，不提前填入贡献。 |

两项分别负责“提什么”和“如何实现”，用同一条件对象与分阶段证据连接。**先做强两条，不预设第三条。** 若同一 H 权重的 T 部署端点也改善，可作为贡献二中“几何监督迁移回离散 DLM”的机制证据；没有 T 端点及对应对照时，辅助 T loss 不能让 H-G 自动成为纯离散扩散方法。

## 结果出现后，怎样保持同一主问题

- **H-G native 与 refined 均有可靠收益：** 主线采用共享语言骨干的混合表示生成，集中解释完整几何状态与连续监督解决了哪些实现误差。仍需承认额外训练、表示、监督和 sampler 同时变化，不能把整项差值指定给某一组件。P 在 G 中是条件/rank，不能讲成它调度连续更新。
- **H-G 只有 refined 端有效：** 可以讲提案/初始几何与固定后端的组合效用，证据只支持更好的系统输入或兼容性；不能写成 native 稳定性已提高。是否值得成为论文主线同时看增量大小、成本和贡献辨识度。
- **H-G 两端均差：** 记录这一预算下的负结果，回到经过修正评测确认的 K4/K8 或此前有效路径，继续解决相同的条件实现问题。它不证明连续模型普遍无效，也不能用跨 cohort 的历史最高数直接代替新对照。若离散路径尚无稳健新增益，就暂不宣称贡献二已成立。

论文主表从模型生成的组成出发，按共同 R/hull 协议报告完整 de novo 请求的 Strict/Meta SUN、组成/结构有效性、N/U、verified SUN 与全部成本。为了配对比较而缓存同一次上游抽样，不等于给模型提供测试集真值组成，但必须交代来源。固定 C 的重建、消融或条件风险均放机制诊断；不能用 CSP 匹配率替代主任务。native SUN 仍经过共同物理评估；后续按注册规则放大验证并报告不确定性。

**明确留在方法/实验说明中的基础：** 未修改的 model494、CIF/图/FP32 回环、来源身份、DDP 与 checkpoint 验收、缓存修复和完整分母都支撑结果可信，不列算法创新。语言预训练、S/P 控制与“DLM 不可替代性”未证实的部分从摘要贡献句中删除。正文可完整保留 LLM+DLM 架构，但论文的强度由两项方法增量与其证据承担。[主张边界](CLAIM_AUDIT.md)、[H-G 故事边界](V3_STORY_FIT.md)
