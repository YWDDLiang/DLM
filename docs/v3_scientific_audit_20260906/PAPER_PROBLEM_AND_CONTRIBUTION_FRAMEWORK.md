# 从化学提案到周期结构：论文问题与贡献框架

2026-09-06。约两页定位草稿；以效果和可支持的科学结论共同决定主线。H-P33 正式训练与评测尚未形成最终结论，本稿不更改其合同，不预填结果。

## 统一问题：What / Why / How

**科学问题：语言模型提供的化学提案，怎样经由可学习的周期几何实现，变成更多稳定、独特且新颖的晶体；其收益有多少来自选择了更容易实现的化学组成，有多少来自给定同一组成后的生成能力？** 研究对象限于当前无机晶体任务与声明的元素/价态支持，不外推真实可合成性。

**What——研究提案到结构的实现缺口。** 设 C 为硬组成与 N，S 为软提示，P 为元素程序，X=(L,F) 为几何。用

`(C,S,P) ~ q_phi ;  X ~ p_theta(X | C,S,P)`

组织一个统一生成系统：LLM 侧学习探索哪些化学提案，DLM 侧学习怎样实现其周期结构。这里的“统一”指共同条件分解、互补职责和可归因的结果；当前参数共享发生在 LLaDA 的 T/G 两模式，上游 Typed Llama 是单独冻结的模型。这个分解本身不是新定理，也不预设 S/P 含有可识别的控制信息。

**Why——化学合法、几何可生成与物理稳定是不同事件。** 可达化学见证不能保证存在低 hull 结构；数字可解析或去噪风险下降也不保证 SUN。已有 FlowLLM 已指出离散化学与连续精度的互补，并用学习的 LLM 初始分布接 RFM；CrysLLMGen 已实现独立 LLM 与晶体扩散衔接。因此“首次结合 LLM 和 diffusion”“LLM 懂化学、diffusion 懂几何”都不够。我们要回答的是：**明确化学支持后，怎样让语言骨干真正承担可测的几何实现职责，并把其增益与组成分布、外部精修区分开？** [FlowLLM §4–5](https://arxiv.org/html/2410.23405v1)、[CrysLLMGen §3–4](https://arxiv.org/html/2510.23040v1)。

**How——两个机制、两层比较。** 第一层在可完成的化学动作支持内学习提案分布；第二层在保持硬 C 的条件下学习周期几何。先固定同一 C/S/P cohort 比较实现机制，再在同一几何实现器下比较上游提案，最后报告完整系统；模块交互单列，不把分阶段差值机械相加。候选假说是：与状态表示相匹配的几何观测、监督和更新能改善固定提案下的 SUN；有用的上游学习还应在相同后端与预算下提供额外收益。任一项均允许被数据否定。

## 两项互补的候选贡献

**贡献一：可达化学支持内的学习式语言模型提案。** C³FD 根据原子预算、电荷、family/arity 和有限氧化态见证计算可继续完成的动作支持；Typed Llama 对 species/count 联合动作学习归一化的 log-linear 残差，输出明确的硬组成及 S/P 接口。其职责是提案分布与化学约束，不能把下游几何成功全部归入此项。

- **需要的证据：** 同一合法支持、抽样规则和固定后端下，C³FD 与加入 Llama 残差的提案比较；报告全请求 SUN、组成覆盖/重复与生成成本。若要归因于语言预训练，还需保留联合动作 head 的合适替代对照，排除只是新增容量或 species/count 非加性表达。非零 KL、组成合法率、使用预训练权重均不能完成这一归因。
- **最近工作与新意边界：** FlowLLM-Types 已隔离过 LLM 化学分布的作用。我们可争取的增量是可达化学 ledger 与学习式联合动作的具体结合及其端到端效用；普通 grammar mask、残差 logits、PoE 名称本身不算独立创新。若 C³FD 属于既有组件，其原有算法只作基础，本篇不能重复认领。当前目标常量、soft 独立抽样、contact-supervised P 也不足以支持“自由属性控制”“物理最优规划”或“语言化学知识已获证明”。[上游代码审计](C3FD_LLM_UPSTREAM_AUDIT.md)

**贡献二：承接相同化学提案的周期几何实现。** 这一条是当前最需要用效果做实的核心，采用连续或离散路径应由最终证据决定。

| 路径 | 具体机制与可用贡献表述 | 必须补齐的归因证据 | 最近工作及不能算贡献的部分 |
|---|---|---|---|
| **H-G 有效** | 共享预训练 LLaDA 的 token construction 与连续几何学习：G 在每个时刻读取完整 noisy L/F，保持 N/E，直接预测联合条件下的晶格 v 与周期坐标场，避免中间 token codec。可写“将 diffusion-language backbone 扩展为共享符号/周期几何实现器”。 | 同 cohort 的 native 与固定 tau800 两端；相同输出的 float/Q 诊断；额外两 epoch 的预算对照。T 辅助、P 与预训练的各自价值只能由相应消融支持；只在需要保留该主张时做对照。 | FlowLLM/CrysLLMGen 已有语言→连续生成；Crystalite 已有完整几何 Transformer 与周期 bias，DiffCSP++ 已有 log-lattice 表示。增量不能写成“发明连续 diffusion / log-SPD / GNN”；共享骨干有梯度只是实现事实。[Crystalite](https://arxiv.org/html/2604.02270v1)、[DiffCSP++](https://arxiv.org/html/2402.03992v2) |
| **回到离散路径** | 从同口径已有效的 K4/K8 或更早端点出发，用一个有实证增益的离散条件更新改善给定 C 后的稳定结构生成；程序可继续控制实际 token 顺序，周期几何信息进入预测。最终贡献必须写出该更新真正改变的状态、目标和采样分布。 | 固定化学 cohort、共同物理/精修算子及可比预算，证明最终学生/生成器的 SUN 增益。若使用 K 候选教师，单列教师覆盖、有效标签、训练成本与学生结果；不能以候选池更好替代学生改善。 | MaskGXT 已证明 masked 离散几何具有建模价值，其主要 CSP 结果不能直接当 de novo SUN 对照。增大 K、复用旧 best checkpoint、加旧模块或给普通 CE 改名都不足以构成新方法；当前尚未确定的稳定性更新不能先写成已实现贡献。[MaskGXT](https://arxiv.org/html/2606.22866v1) |

两项分别负责“提什么”和“如何实现”，用同一条件对象与分阶段证据连接。**先做强两条，不预设第三条。** 若同一 H 权重的 T 部署端点也改善，可作为贡献二中“几何监督迁移回离散 DLM”的机制证据；没有 T 端点及对应对照时，辅助 T loss 不能让 H-G 自动成为纯离散扩散方法。

## 结果出现后，怎样保持同一主问题

- **H-G native 与 refined 均有可靠收益：** 主线采用共享语言骨干的混合表示生成，集中解释完整几何状态与连续监督解决了哪些实现误差。仍需承认额外训练、表示、监督和 sampler 同时变化，不能把整项差值指定给某一组件。P 在 G 中是条件/rank，不能讲成它调度连续更新。
- **H-G 只有 refined 端有效：** 可以讲提案/初始几何与固定后端的组合效用，证据只支持更好的系统输入或兼容性；不能写成 native 稳定性已提高。是否值得成为论文主线同时看增量大小、成本和贡献辨识度。
- **H-G 两端均差：** 记录这一预算下的负结果，回到经过修正评测确认的 K4/K8 或此前有效路径，继续解决相同的条件实现问题。它不证明连续模型普遍无效，也不能用跨 cohort 的历史最高数直接代替新对照。若离散路径尚无稳健新增益，就暂不宣称贡献二已成立。

论文主结果按现有共同 R/hull 协议报告全请求 Strict/Meta SUN，并同时给 N/U、有效终态和 verified SUN、原生→精修转移及成本。这里的 native SUN 仍经过共同物理评估，不是“原生已是物理极小值”。后续按注册规则放大验证并报告不确定性；开发点估计只能决定是否值得继续。

**明确留在方法/实验说明中的基础：** 未修改的 model494、CIF/图/FP32 回环、来源身份、DDP 与 checkpoint 验收、缓存修复和完整分母都支撑结果可信，不列算法创新。语言预训练、S/P 控制与“DLM 不可替代性”未证实的部分从摘要贡献句中删除。正文可完整保留 LLM+DLM 架构，但论文的强度由两项方法增量与其证据承担。[主张边界](CLAIM_AUDIT.md)、[H-G 故事边界](V3_STORY_FIT.md)
