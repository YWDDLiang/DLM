## 能量双目标没有共同改善

同组成下，ΔB=ΔeR，而 ΔA=Δe0−ΔeR。实际数据逐对验证该恒等式，最大残差为0。降低终态能量本身并不保证原生结构更接近终态。

| 交集 | 对数 | Δe0 | ΔA | ΔB=ΔeR |
|---|---:|---:|---:|---:|
| Native 全部有限配对 | 252 | −202.026 | +207.334 | −409.361 |
| Native 双方 verified | 34 | +147.057 | +165.684 | −18.626 |
| Tau800 全部有限配对 | 252 | −22.546 | −12.643 | −9.904 |
| Tau800 双方 verified | 59 | −3.558 | +2.931 | −6.489 |

单位均为 meV/atom，方法减参考。全部有限交集不等于物理验证通过，尤其不能用 tau800 全部有限交集 A 的负变化替代共同 verified 交集的正变化。

共同 verified 的 tau800 中，A、B 同时下降只有12/59对；A变差但B改善有18/59对。A的中位变化为0，B约−0.0019 meV/atom。native 的对应同时下降为4/34对。没有稳定、普遍的双目标收益证据。

## 终态验证下降主要表现为残余应力

丢失的40个 verified 个例逐一对照既定阈值（force 0.1 eV/Å、stress 0.5 GPa）：

| K8 终态观测 | 个数 |
|---|---:|
| 力达标，应力超阈值 | 33 |
| 力和应力都超阈值 | 3 |
| 仅力超阈值 | 3 |
| 生成失败，无终态 | 1 |

因此，当前直接证据是残余应力验收丢失占主导，不能笼统归为所有样本能量变坏或 optimizer 全部发散。标准 attempt 表未保留全部 optimizer/终态一致性错误细节，不能从缺失字段编造原因。报告保留原始标准，不以放宽阈值改变结论。

Strict SUN 的4个丢失可以具体分解：sample0生成失败；55、164、224的终态能量跨过严格 hull 阈值，仍然属于Meta且保持N/U。新增的是68、155。Meta丢失的15个中，1个生成失败、4个失去novelty、10个越过Meta能量阈值；17个新增抵消了一部分损失。N/U的下降也不是同一种原因：8个丢失中2个生成失败、6个失去novelty，新增1个。

## 均值受尾部影响，结构问题仍存在

native 共同 verified 的 A 均值 +165.684 meV/atom 对尾部敏感。最坏 sample245 / In6Yb2 的 ΔA=+9.47579 eV/atom，对原均值贡献 +278.70 meV/atom；去掉它后的均值会变号。但预先规定的对称各10%去尾均值仍为 +125.294 meV/atom，因此不能删除一个案例后宣布改善。

该 In6Yb2 的输入 V/N 从46.4117降至12.7358 Å³，最小原子对距离从2.12421降至1.425 Å。旧 K4 讨论过的缩胞问题在 K8 中仍然出现。另一个全部有限交集的极端例 F6MgSn（sample72），V/N从20.6852降至1.70348 Å³、晶格条件数从3.77升到16.84，ΔA达到+113.225 eV/atom；它不能被当作已验证的稳定改进案例。相反方向也有巨大改善的原参考坏例，说明均值混合了两边不同的严重尾部。

native 共同 verified 的 B 均值 −18.626 meV/atom也较集中：sample112 / CeTl3 的贡献约−17.633 meV/atom。tau800 的量级较小，但仍应报告敏感性：A对称各10%去尾后为+1.455 meV/atom；B为−3.775 meV/atom。原始均值与全部请求分母始终保留。

完整报告使用保存的全晶胞矩阵和125个周期像计算距离。tau800 的输入几何来自真实 refined structure，不用上游 native body冒充它。有限 image shell 不等于对任意极端未规约基的精确最近像证明。

## 目前能解释到哪一步

**已核实：** 固定组成、Planner/program、采样种子、批次、回放接口、共同终态协议及hull来源通过配对检查。K8 teacher拟合的是native路径及其共同弛豫标签，没有把固定model494 tau800映射纳入训练目标。tau800后有明确的novelty、阈值和残余应力转移，native也仍有严重缩胞尾部。

**合理但未隔离验证的假设：** native权重调整改变了连续后处理进入的区域，公共refiner可能削弱一部分native增益；终态能量目标与原生接近终态目标存在实际的收益分配；候选支持不足和student泛化误差可能限制K8增加候选后的收益。当前组合改变了多个组件，不能把全部差异归因于单个loss系数或仅归因于K=8。

因此继续按预登记最终K8点完成独立1200请求主评测，不用开发集挑一个看起来更好的中间checkpoint。本轮新DLM则针对已定位的条件来源、程序前缀、监督分母和周期交互问题进行独立验证；这些修改不构成将来tau800必然提升的保证。
