## 当前判断与B的作用

可以确认的瓶颈是：现有自生成候选离近平衡很远，teacher在这个差参考上只作了
很弱的重加权。K4等组成平均A从6.5386变成6.5161eV/atom；即便忽略B、每组
挑最小A，均值仍5.4842。不能期望单靠同池重加权学到大量不存在的低A终点。

B衡量共同R后的盆地能量相对hull，是热力学Stable的核心量；它不控制原生A、
force/stress，也不等价于SUN。压低B均值还可能不增加越过0/0.1阈值的样本数。

首轮tau800的逐请求计数已核实：严格Stable28/256=10.9375%，其中9个不新颖，
Strict SUN因此只有19/256=7.421875%；Meta Stable160/256=62.5%，其中34个
不新颖，Meta SUN为126/256=49.21875%。没有额外的“新颖但不唯一”损失。
所以在系统端，仅继续降低B不能解决全部SUN缺口；原生端仍以低能/近平衡能力
不足为主要瓶颈。不能用Stable替换SUN宣称达标。

## 只准备一个额外方向

固定自生成起点，用现有DLM的同一个修订核提出多个实际修订，检查它是否能改善
自己的晶体。先验证候选支持，再决定是否有根据作整轮自提升；不再同时试多条路线。

支持检查采用已冻结的前128个train条件，各自固定K4旧池candidate0为起点，
使用首轮正式policy39892，在每个起点采4条修订，共512请求。起点来自先前warmup
模型的自生成路径，不是GT，也不声称它们是当前policy的无条件on-policy输出。
修订动作则由当前正式policy在该固定状态上实际采样。

- 起点不按能量挑选，candidate0失败则保留4次失败，不换candidate。
- 独立的`self-repair-v1:parent_trajectory_id`种子域避免复用产生起点时的噪声。
- `trace.initial_body`是完整起点；只运行cooperative/closure，全部尝试及回滚都保留。
- 起点的原R标签作比较基线，不伪造no-op路径。自然得到原样输出则保留完整轨迹概率。
- 对比双方verified的delta A/delta B；缺失基线不填能量，单列验证变化。
- 同时报告均匀修订结果、按起点等权结果、单条共同改进覆盖和无KL约束的凸支持上界。
  候选oracle机会不能写成新学生或部署best-of-K的性能。

相对起点不退步的约束不一定可行：修订均匀分布u可能比起点更差。
旧teacher先减组均值，不能直接传入delta就声称实现了逐起点不退步。
如果后续训练，需另行核验这一目标和旧策略约束；当前训练器仍拒绝round2，
因此此检查不能误入既定K8最后训练。
