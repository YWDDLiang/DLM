# 顶会 de novo 晶体生成：科学问题与论文组织

2026-09-06。按用户要求，仅以已核实的ICLR、ICML、NeurIPS主会论文作为本次写作参照。阅读对象为摘要、引言、任务定义、贡献段及对应实验组织；以下是主审的结构化归纳，不是原文引述，也不借用其性能数字作为我方结果。

## 首先固定主任务

**我们的任务是de novo晶体生成：模型提出组成，并生成与之对应的周期结构。** 上游自己生成组成、下游以该组成为条件，仍可组成完整de novo系统。缓存同一批自主生成条件比较后端，完整输出仍是de novo样本，配对差值用于后端归因；给定外部目标组成的CSP不能替代主任务。de novo也不要求每个生成化学式都从未出现，具体新颖性沿用声明的结构N/U判据。当前256的上游来源与完整请求记账已[单独核实](DE_NOVO_COHORT_ACCOUNTING.md)。

这一边界在[FlowMM的ICML 2024官方页面](https://proceedings.mlr.press/v235/miller24a.html)和引言中被明确区分。本文应以整个组成—结构生成分布及完整请求预算组织主表；固定C/S/P配对、raw/refined分解用来解释主结果。

## 三篇最接近语言路线的写法

[语言路线细读](TOPCONF_LANGUAGE_STORY_PATTERNS.md)核对了 **FlowLLM（NeurIPS 2024）、GenMS（NeurIPS 2024）、CrysLLMGen（NeurIPS 2025）** 的官方主会页面和正文。其共同写法是从完整材料生成/发现目标提出关键缺口，再让阶段分工与主任务证据呼应。混合语言模型与连续生成、语言先提公式再生成结构等总体分工已有先例，我方必须说明具体新增机制及其效用。

这些论文的贡献段并不都列出三个独立算法：有的是统一方法、主要实证与机制分析。用户要求的2–3项方法贡献应由实际互补增量承担；优先做强两项，第三项只有在稳定性改进具备独立证据且服务同一问题时加入。

## 我们的引言应怎样落笔

以下是待结果支持的写作骨架，尚非摘要贡献定稿：

1. **科学目标与价值。** 从组成与结构的联合空间直接发现稳定、新颖晶体，以生成模型减少昂贵的候选搜索与验证负担。先界定允许的化学空间和稳定性代理，不外推实验可合成性。
2. **核心困难。** 组合化学选择和周期几何具有不同约束、彼此依赖；有效组成、可解析结构和稳定新颖产物是不同事件。
3. **已有工作后的具体缺口。** 由实际审计和结果指出当前语言参与的生成链路在哪一步失效、代价在哪里。不能仅复述“LLM擅长离散、diffusion擅长连续”，也不能把更换骨干名称本身当新科学问题。
4. **一个总思路与两项互补机制。** 候选机制一负责有依据的化学空间探索；机制二负责将生成条件实现为周期结构。H-G有效时准确写共享语言骨干的混合几何学习；回到离散时写出实际有效的离散条件更新。两者均需服务端到端de novo产率。
5. **证据与边界。** 主结果报告完整系统的全请求SUN与成本；固定生成条件、输出精度、T/G及上游对照解释来源。未经消融支持的P、soft控制、语言预训练必要性从强贡献句中移除。

当前可用的总问题表述是：**如何利用语言与扩散式生成建模，在组合化学和周期几何的联合空间中，提高稳定新颖晶体的发现效率？** 这是领域目标与研究切入，不能称为首次提出的新任务。真正的问题贡献应由我们发现并验证的具体缺口来收紧，方法贡献由相应稳定性增益和机制证据落实。

V3的两端结果将决定方法分支；我方不会为了匹配已有模块而把主问题降为CSP，也不会用已注册的同条件后端诊断代替完整de novo系统证据。更完整的条件贡献草稿见[论文框架](PAPER_PROBLEM_AND_CONTRIBUTION_FRAMEWORK.md)。
