# V3 实际失败：八端点的共同模式与下一步

2026-09-07。**首选候选是同一 V3 最终权重的 T construction-only 部署。** 本批最明确的问题是 G 原子相对位置的初末变化很小，未消除随机初态的短接触；G 精修后又比 K4 少形成能量达标结构。数据不支持直接把它修成“统一扩胞”“减少重复”或“加更多积分步”。这不是已经证明 G 存在某个代码 bug，也不保证 T 有效；冻结逐步轨迹还需区分弱输运与途中往返。

本分析只读两个导出的完整 case 包，执行 CPU 统计与几何计算。没有模型/MLIP forward、新弛豫、SSH、GPU或生产代码修改。末态 N/U 与 S/SUN 均沿原全256 evaluator，不按本次分组重新计算唯一性。

G native 的 Meta 互斥分解为：61 SUN、148 有有限终态但高于阈值、39 已知 hull 但没有有限终态能量、8 unknown hull。40条 `invalid_raw` 中1条同时 hull unknown，所以不能把这两项直接相加。G τ800则为116 SUN、27稳定但N/U不通过、105高于Meta阈值、8 unknown。生成器输出可解析的256个结构，并不表示全部通过物理输入检查。

G自身经τ800：Strict SUN保留2、失去7、新增11；Meta保留36、失去25、新增80。精修有大量收益和实质丢失，不能只描述其中一边。

晶格确有变化，不能说整个结构原封不动。坐标相对输运很小，与随机初态的几何问题保留一致：prior有35条最短距<0.5 Å，其中只救回3条、保留32条，同时新引入8条，最终40条。仅替换晶格而保持prior坐标的几何诊断也有40条短接触；仅替换坐标保留prior晶格有36条。后两项只是未打能量的几何重组，不是新生成策略的实测结果。

这40条经τ800后有16条Meta S、15条Meta SUN；其中一些组成显然可由已观测流程实现更好的结构。碰撞是 G 的真实失败，但单做碰撞推开仍不足以解释或修好精修后低于 K4 的能量稳定数。

固定验证中，coordinate MSE在band0/1/2从第一轮的1.04055/0.98497/0.97396变为第二轮的1.04083/0.98456/0.97323，几乎没变；band3为0.15716→0.15725。这与上述初末行为一致，单独这些loss尚不能定位到哪一个训练或输入环节。根任务的精确零预测对照与冻结逐步轨迹负责进一步定位，不能由此处初末位移冒充逐步证据。

## 5. 剩余窗口内的一个首选改动

**首选：同40064最终权重，全部256请求统一改用T construction-only生成；再按固定tau800与共同R评价。** 作用点是几何生成分布：使用已接受T监督的离散晶格/坐标生成，取代当前几乎保留随机坐标的G先验输运。保持上游条件、同源种子/逻辑批次、已有权重与全部失败账本；不在T后叠加缺乏实测坐标作用的G，也不按N、case或输出SUN选择T/G。

这无需新增训练，已有接口映射及正确V2 construction 12/44 baseline可复用。constructor→tau基线必须单独补齐，不能误用repair→tau的16/113。它是同一V3训练产物的另一种部署，不应写成已经修复G算法。

**可靠成功例的保留与反证。** T仍学习MP20的离散结构和真实P执行，可望提供比均匀随机坐标更有结构的生成起点；但共享训练可能损害T，离散精度也有限，现有V2 construction的Meta较弱。因此没有逐例保留保证，须统一记录上表中可靠成功与新丢失；不能救回NiGd3的无效终态来冒充提升。若T的整体raw/refined未改善，就停止把“换读出”当已获支持的修复，回到已有效的旧路径再选择一个有对应证据的改动。

**本报告不凑第二个候选。** 固定参考概率混合尚无同状态动作分布证据；K4和参考存在共同失败且主要尾部早在构造阶段出现，无法从端点平均数推出混合会保留好例。统一扩胞与简单去碰撞也受上述数据反证。G更多步或任意放大u可能只放大无用场；是否存在容易修复的数值问题由当前冻结轨迹核验决定，不能先承诺。共同R/hull/N-U不变，本批数据只用于机制诊断与统一方法选择，不形成按ID的策略或新训练标签。
