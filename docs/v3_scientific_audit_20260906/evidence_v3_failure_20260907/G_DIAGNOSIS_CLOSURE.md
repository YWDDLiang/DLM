# G 诊断结论：关闭本轮积分器假说扩展

2026-09-07。依据全部256产物、100来源的精确零场基准及最后两个事先选定的原logical batch重放；不再追加G probe或改生产代码。

**主要证据指向坐标场的有效预测不足，当前没有“只改积分器或第33读出就容易修好”的支持。**

- [CPU40069零场基准](ZERO_VALIDATION_BASELINE_40069.json) 复现同100来源、相同band噪声/权重，0模型forward、0GPU调用。epoch2的u风险相对零输出改善，在t=.00447/.02236/.1/.316分别为 **−0.0365%/−0.0661%/+0.0189%/−0.3056%**；高t本应接近零的target也没有得到良好匹配。相反，v在两个最高t段改善 **25.5%/32.4%**，不能将整个模型归为未加载或完全未学习。
- [全256输出分析](GEOMETRY_FIELD_SAVED_ANALYSIS.json) 显示内部F净位移RMS中位仅 **.005585**，近碰撞 `<.5Å` 从prior的35个变为40个；晶格z改变量RMS中位为.4843。坐标端与晶格端的行为明显不同。
- [最后冻结重放40071](G_TRACE_40071.json) 选的是原序首个N≤6完整batch（N2，sample12）和首个N≥16完整batch（N16，sample146），没有使用SUN选case。共 **66次原NN调用**，FP32输入重建、原最终fractional/Gram偏差均为 **0**。
- 两例Euler累计内部fractional RMS分别 **.008140/.008325**，累计/净比 **1.30/1.58**；没有大运动被往返抵消的迹象。第33读出的内部变化仅 **1.63×10⁻⁵/1.56×10⁻⁵**，也没有抹掉已生成大结构的迹象。

两例不能证明所有case都已精确积分；近零预测风险差也不独自识别表征、条件不可约方差或优化中的唯一原因。但三组证据一致，足以在当前时限内降低“多加步数、改时间尺度、放大score或删读出”的优先级。没有发现简单的σ/单位/符号错误，工程通过也不能代替坐标学习。

本轮G诊断到此闭合。保留原G/Q结果和限制，后续重点转向已恢复的T部署及依据实际K4/K8产物登记的改动；不泛泛延长V3训练，不改共同R/hull或分母制造收益。
