2026-09-07 上海。只读现有产物与实现，未改生产代码、调用模型/GPU/MLIP或开启训练。输入为 [v3_cases.json](v3_cases.json)，SHA256 `4c7ef1d35943fb331c38a039e1833519f83b90ce77130849f1818b235913d84b`。全256逐请求计算与汇总见 [GEOMETRY_FIELD_SAVED_ANALYSIS.json](GEOMETRY_FIELD_SAVED_ANALYSIS.json)，由 [独立分析脚本](diagnose_geometry_field.py) 生成。

**当前最强线索是：晶格在明显变化，坐标相对随机初态仅有很小的内部重排，连近碰撞总体也没有改善。首先核对坐标场相对零场究竟学到了多少；目前不足以把“只加积分步数/调末端读出”列为容易奏效的修复。** 这不是由某一个≈1的 MSE 单独得出的判断。

## 1. 实际输出先排除了哪些解释

| 同256请求 | float raw | tau800 | Q raw |
|---|---:|---:|---:|
| 重建成功 | 256 | 256 | 256 |
| N∩U | 256 | 224 | 256 |
| Strict/Meta stable | 9/61 | 20/143 | 6/58 |
| Strict/Meta SUN | **9/61** | **13/116** | **6/58** |

因此不是缺失大批样本或 pure codec 失败使 raw 分数低。Q 比 float 更低，也没有将成绩救回；refined 另有稳定性与 N/U 的共同限制，不能把13/116只归结为去噪几何。

从所有256原始结构独立计算（有限125-image shell）得到：

- 最小距离 `<0.5 Å`：初始 prior **35** 个，最终 **40** 个；`<1 Å`：**142→142**；`<1.5 Å`：**215→209**。最小距离中位 **0.94632→0.91176 Å**，最坏最终距离0.17939 Å。
- label 的 `raw_min_distance_A` 只对216条有值；其余40条为 invalid_raw。首报若只统计非空 label，会低估近碰撞数量，不能据“可重建256”称物理输入全部有效。
- 每原子体积中位 **18.9628→19.0993 Å³**；`log(Vfinal/Vprior)` 中位−0.00109，最终晶格条件数中位2.737、最大8.181。没有“普遍缩胞”或严重 chart 奇异化的总体证据。
- 标准化 lattice z 的改变量 RMS 中位 **0.4843**；六个最终 z 通道标准差约 **1.03–1.29**，并没有压成一个全局均值。
- F 的周期净位移 RMS 中位 **0.011918**，但去整体平移后仅 **0.005585**。公共平移占每胞位移平方的中位 **77.83%**；平移本身不改善相对配位。平移不变的 pair-fractional 改变量 RMS 中位仅 **0.007898**。
- raw Strict 的9个中，8个是N=4、1个N=6；N≥8没有Strict。组成难度也可能参与此分层，不能只凭它证明原子数是单因果原因。

这里的位移只是净变化：很大的往返运动也可能得到小净位移。现有记录没有中间场，尚不能排除这种情况。有限 image shell 的诊断也不被提升为任意晶胞的全局 MIC 保证。

已提供 [zero_validation_baseline.py](zero_validation_baseline.py)：读取实际 train40064 的配置/validation log、相同100 keys及连续身份，按 `geometry:validation_band_b`、epoch0、真实 max_sites 重放 CPU 噪声和FP32 targets，比较准确的零-v/零-u MSE。它验证源文件hash、唯一覆盖与每band权重，输出两epoch相对改善及范数的三角不等式界；不加载8B、不做600次forward。该脚本已通过两来源六band的确定性 CPU smoke，真实100来源结果待主审执行回传。

**可证伪条件：** 若实际 u 风险在有信息的多个band显著优于零场，并且冻结模型的 u 与target有正确尺度/方向，H1应降低优先级；若几乎不优于零场且大N输出仍接近随机排列，则不能指望积分器创造网络没有预测的结构。后者仍不独自识别学习率、任务梯度竞争、输入表征或数据条件中的哪一个根因。

## 3. H2：离散积分或末端读出丢失了已经学到的几何信号

对照实际代码，`u=t*score` 与 `F←wrap(F+Δt*u)`、`v` 与 `z←z−(π/2)Δt*v` 的单位和符号一致，末端是重新评估后 `Fout=wrap(Fε+εuε)`、`zout=αεzε−σεvε`。目前没有发现一个可直接修掉的缺σ/重复σ或反向符号错误。

32步网格最大Δt **0.0614004**；time embedding 最高频率为1000 rad/单位t，该步跨约 **61.4 rad**。这是需要检查的数值尺度，不是已学场有同等振荡的证据；训练可能已抑制这些高频分量。不能据此直接修改 time_input_scale，或随意乘大 u。

现有 paths 只有 initial prior 和 final structure，没有 FP64 pre-ε 状态、最后 v/u 或逐步速度。因此不能从最终CIF区分“场弱”“大幅往返抵消”“最后读出抹掉结构”。最小冻结诊断仅需少量事先选定的完整原logical batches：

1. 原32步，记录各步v/u范数、累计位移与净位移，保存pre-ε及第33读出的变化；不增加候选选择。
2. **仅在H1/轨迹支持有可用场时**，同prior、同模型与同readout比较32/64步的结构差，先作数值诊断，不立即扩大到整256的物理重评。

若读出变化很小且累计运动也小，H2不是主修方向。若已有协调运动却被粗网格或最后一步明显破坏，才有具体、预算小的 V3 推理修订可登记。增加NFE本身、改温度或重新训练都不是上述证据的自动结论。

本轮先等精确零场基准，保持原G/Q结果；不以新阈值、过滤掉40条无效输入或改变共同 R 来制造提点。
