# Method at a glance

C³FD supplies a declared reachable chemical support. Typed Llama reweights typed actions and predicts soft hints; the pointer supplies a species program. Exact N and element counts constrain the dynamic 7+4N crystal representation. These are different roles from producing stable geometry.

The completed V2 uses shared LLaDA hidden states, a periodic state conditioner with one-hop messages, and geometry attention to construct and repair numeric tokens. A fixed model494 refiner supplies a separate endpoint. Soft hints are not space-group constraints; a learned program is not yet proven better than canonical order.

Global attention makes information accessible. Explicit geometric features change which computations and gradients are available, but neither nonzero gradients nor periodic distances prove a SUN improvement. The actual V2 construction/repair/refined results and their denominators are in [current state](../CURRENT_STATE.md).

The proposed [H-P33](../v3_scientific_audit_20260906/V3_H_P33_SPECIFICATION.md) keeps the pretrained LLaDA backbone and token construction task, while adding joint continuous lattice/coordinate denoising. It is a mixed-representation candidate with an explicit finite sampler. P supplies conditions in its synchronous geometry mode. Source identity, independent review, implementation checks and SUN evaluation remain necessary.

The retired G2 scientific-salience explanation and old numerical headlines are preserved in the [historical manifest](../v3_scientific_audit_20260906/historical/paper_entrypoints_before_refresh/MANIFEST.json); they no longer define the current architecture or evidence.
