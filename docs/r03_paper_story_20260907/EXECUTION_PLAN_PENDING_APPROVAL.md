## 3. 最终推理链与模型职责

```text
原 H1A2 P0 从原提示开始生成 formula
       ↔ 公式前缀/BPE 桥接器 ↔ 最新 C3FD 可达性支持
       ↓ 合法公式结束后，解除公式约束
同一 H1A2 P0 按原流程续写其余六行 rich Plan
       └── 外接的新控制头读取原 P0 特征，输出物种程序 P
       ↓ 原七行 rich parser / 原 B0 body prompt；P 为独立元数据
R5-C B0 + R03 safe-axis 初始构造
       ↓ 保留组成、原生结构与逐步记录
几何支持内的 Llama-programmed DLM 局部修订
       ↓ 原生终点
冻结 model494 / tau800
       ↓ 共同物理评价、N/U 与官方 hull 协议
正式 SUN
```

组成与其余 rich 字段由同一原 H1A2 P0 生成。C3FD 限定公式解码中的可行支持，合法 token 的偏好仍由 P0 原评分决定；控制头附加在冻结 P0 特征上。没有独立 Typed Llama 生成器、soft-prefix Rich Expander，也没有新的 rich SFT。

### 3.1 rich 接口保持历史语义

对外仍严格输出七行：formula、anion、charge、lattice、spacegroup、volume、end。formula 的 token 由原 P0 生成，C3FD 只约束其合法支持；到第一个公式结束换行后，该约束接口停止干预，P0 继续生成其余 rich 字段。

P0 权重、原 prompt、tokenizer、rich 字段分类含义、parser 和 B0 body prompt 保持原样。同一完整 token 前缀下，退出约束阶段后的 P0 logits 应与原路径一致；因为选到的公式可能改变，后续字段的实际取值当然也可能随条件变化。不能声称整个组成分布或所有输出逐字节不变。

不存在公式外部采样、预先固定另一模型的完整 formula 再交给 P0 展开、额外 prefix embeddings，或将 Compact 的三个 head 映射成旧 rich 字段。缺字段或原解析失败仍按失败记录，不代填科学值。此前的 F/M Expander 路线从本轮执行范围删除。

### 3.1a 直接接入的必要桥接

[`ccfd_logits.py`](../../src/crystal_dlm/ccfd_logits.py)已有只干预 formula、换行后退出的 logits processor；[`sample_llama_h1_formula_plans.py`](../../src/scripts/sample_llama_h1_formula_plans.py)已有调用位置。但现成 `phase0_assignment` 模式主要是词法前缀检查与公式结束时的旧价态判断，并非最新 C3FD v2.5 的逐前缀可达性，不能改名后当作完成。

升级时需要：

- 将候选 BPE token 对应的完整文本前缀映射到所有兼容的化学语义状态，保留元素缩写与多位计数歧义；不将 raw typed logits 与 BPE logits 直接相加。
- 对语义状态使用最新的可达性逻辑，只有仍存在合法完成路径的下一 token 才可采样；换行仅在完整公式合法时开放。
- 不另行从 C3FD 抽 N/family/arity 强加给 P0；对兼容的终态目标保留可达候选集合。原公式书写顺序不强制改成 Typed Planner 的 canonical 顺序；文本到语义集合的适配需要明确处理这一差异。
- 原 H1A2 如果已经采用 formula prefill 就沿用；若原提示没有 prefill，则动态定位 formula 字段，不为复用旧 processor 而偷偷换 prompt。
- 在公式阶段以外返回原 logits；保留原采样超参数。合法 token 的原评分不变，不等于对所有合法完整公式做精确的全序列条件化。
- 缓存词法映射与语义可达状态，实测 CPU 开销和解码吞吐。桥接若达不到正确性或预算要求，报告具体障碍，不自动切回 Typed Llama＋Expander。

这部分验收是新桥接实现的正确性检查，不重新核验旧 C3FD 的 100% 实验。新接法也不能仅凭旧 decoder 成绩就免除接口检查。

### 3.2 Llama 怎样实际调控 DLM

本轮采用最小且明确的控制范围：**保留 R03 初始轴顺序，Llama 决定完成结构后需要访问的物种及修订顺序。** 不直接换成旧 SPAD 的 anchor-first 初始构造，避免在适配 C3FD 的同时破坏 R03 的初始条件过程。

控制头输出全部已有物种的一个排列；编译器取最前两个不同物种的固定 anchor，在一个固定回填轮次中按已声明的逆序访问。单元素体系访问一个，N/元素/计数不变。同物种 anchor 的选择规则固定，不将其归因于 Llama 学习。

控制头读取原 H1A2 在公式完成位置的隐状态及元素/计数。训练与推理使用相同的原 prompt/公式文本条件位置，不依赖 teacher-only soft 字段，也不把旧 Typed Llama 隐状态直接传入新头。rich 文本生成与程序输出使用这份冻结 P0 的特征；控制头训练不更新 P0 的 LM 权重。

如本轮只控制修订阶段，论文据实写该范围，不声称 Llama 已控制初始 X/Y/Z 排列或实时读取 DLM 每一步重新规划。

### 3.3 引入哪些几何机制

- 保留 exact `7+4N`、N/元素预填、R03 全局轴依赖和旧 tokenizer。
- 迁入周期坐标别名合并、候选 Z 的周期距离约束、晶格可判定依赖；新增约束与原 R03 控制分开登记。
- 回填时掩码一个 XYZ，保持其余结构可见且不变，内部仍按 X/Y/Z 条件顺序求值。
- 空合法动作支持在修订中回退到原位点；原位点本来无效时仍记录无效，不用回退伪装修复成功。初始构造无合法完成则记录失败，不能无限重采样。
- 不扩展词表，不改变数值精度，不默认引入 G2、V3 连续头或联合晶格/多原子全局重写。

这里的依赖顺序和几何支持有历史依据，但进入旧 B0 后的增量仍属于新实验。固定周期像搜索的数值范围和几何判据原样声明，不写任意晶格的理论全局有效性保证。

## 4. 训练计划

### A. 取消 rich Planner 重训，改为公式解码桥接：核心必做

H1A2 P0 完全冻结，不训练 LoRA、prefix projector 或新的 rich 字段头。工作量用于公式阶段的最新 C3FD 语义桥接、词法/BPE 边界、换行退出和吞吐验证。节省的 rich SFT 预算用于接口质量与正式主结果。

### B. H1A2 程序控制头适配：核心必做

- 在 A 的原 prompt/公式位置接口固定后，提取冻结 P0 特征，只训练 pointer head。
- 复用 MP20-train 周期接触关系生成的确定性物种排列监督；保留全部可表示来源，不使用测试结构、hull、SUN 或正式生成结果造标签。
- 采用既有 pointer 结构、初始 LR `1e-3`、一个 pass；输出必须是当前组成元素的合法排列。
- 报告相对固定顺序的排列准确率、实际非固定程序比例以及执行 trace。接触顺序准确率不是能量或 SUN 最优性证据。

### C. 对旧 B0 做什么

核心候选的初始构造始终使用原 B0，不做全量重新 SFT。首先直接检验原 B0 在 R03 结构上的受约束修订行为。已有接口兼容或平均 loss 良好不视为 SUN 改善。

### D. 复用 K4/K8 的离线物理适配：不新采样、不新标注

在 T+5.5 小时方法冻结前，用现成物理数据做一次短训：

- 复用 K8 现成候选、已验证标签及 teacher 权重；K4 consistent v2 补充可用条件组，不重复放大同组成权重。旧验证候选记录为 K4 972 条、K8 1843 条，实际兼容数量在接口整理时报告，不将它们相加当作独立组成。
- 不新生成训练组成/候选、不运行新的训练用 model494、CHGNet、力或弛豫标注；只建立索引、字段/slot 对应与普通 masked 训练视图，物理结构和标签不变。
- 不直接运行旧完整路径训练器替换 checkpoint；改为物理质量权重指导的离线 masked 修订适配。保留实际可恢复条件；缺少 rich 条件时不编造，修订阶段的共同字段视图在 G/P 中一致，原 H1A2 rich 和 R03 构造不变。
- 从原 B0 副本训练仅用于修订的 LoRA，LR `1e-6`、最多 256 更新，使用原 B0/MP20 保持项；旧构造权重及 embedding/head 不动。禁止直接混合 K4/K8 模型权重。
- 这些主标签对应原生结构的 CHGNet 弛豫反馈，不称为 model494 后的回报。已存在且用途为 train 的 tau800 标签才可另行登记复用；没有就不补采，更不能使用 evaluation 标签训练。
- 若数据不兼容、训练无效或时间不足，保留核心 G；不启动新采集/标注补救。具体兼容性与归因边界见[K4/K8 复用方案](K4_K8_REUSE_PLAN.md)。

程序学习与物理续训都只做一轮；不开展多 LR、多 epoch、多 seed 挑最优。

## 5. 开发对照与最终方法冻结

开发集合：另行固定 128 个 de novo 请求，与正式主表分离；不读取正式 SUN 选择方法。必要的组成、模型状态、采样种子及失败均留档。

| 开发角色 | 内容 | 目的 |
|---|---|---|
| 接口控制 I | 最新 C3FD 仅约束 P0 的 formula → 原 P0 rich 续写 → 原 R03/B0 | 检查公式约束接入的分布影响 |
| 核心候选 G | I + 几何支持 + Llama-programmed 一轮局部修订 | 检查新增执行机制；同时保存修订前后结构 |
| 扩展候选 P | G 的构造不变，只换成物理续训的修订 checkpoint | 检查物理学习是否真正改善学生输出 |

G 必须保持组成，程序执行正确且完成质量没有明显故障。若新回填造成大量非法/未完成结果，先修接口；不能直接删除失败位点或以能量筛选遮盖。超过方法冻结时限仍无法形成有效的 Llama 控制候选，应交付 I 的结果和未完成项，不能把 I 宣称为满足全部老师要求的最终法。

P 的预先采用规则：在该独立开发集合中，Direct 不低于 G，Strict/Meta SUN 均不低于 G，且至少一个 SUN 计数增加，才作为正式候选；否则保留 G 并报告 P 的结果。该规则只是开发选择，不证明统计显著性；正式主结果使用全新请求。不得为通过规则换 seed、挑子集或追加轮次。

**T+5.5 小时必须冻结最终候选**。此后只修阻止同一协议完成的工程故障，不再换模型、改采样温度或调科学参数。

## 6. 正式主实验

主表只有两臂，各 1000 次 de novo 请求：

| 主表行 | 上游 | DLM 构造/修订 | 后端 |
|---|---|---|---|
| R：保护的 R03 对照 | 原 H1A2 P0 | 原 R5-C B0 + R03，无新增组件 | 固定 model494/tau800 + 共同评价 |
| M：本轮最终方法 | 原 H1A2 P0 的 formula 接最新 C3FD 可达性；其余 rich 续写不变；外接程序头 | R03/B0 构造 + 已冻结的 G 或 P 修订 | 相同 model494/tau800 + 共同评价 |

每臂分成两个独立上游 seed、每 seed 500 次请求；它们重新生成组成，而不是同一 256 Plan 的 CUDA 重复。正式与开发 seed 空间分开，所有种子在运行前写入 manifest。两臂上游分布不同，因此主表回答整体系统效果；开发共同组成对照用于结构实现归因。

保留 R03 body 默认：temperature 0.7、CFG 0、low-confidence、最大 batch8；固定已登记的每请求/阶段随机数。不同 worker 排布不改变样本索引、候选次数或科学参数。model494 保持 tau800、固定 checkpoint 及每请求种子；不要求 800 步 CUDA 路径跨进程逐字节一致。

同时报告最终原生与精修后端点的 comp/struct/joint validity、N、U、SUN、失败与 unknown。保存修订前原生结构，开发集合评价其变化；正式样本的额外中间态物理评价在有预算时补充，不挤占两个主端点。

使用相同 CHGNet/弛豫参数、N/U 参考和官方 GGA/GGA+U hull 口径。启动时锁定实际可用版本与缓存身份；若新化学系统缺缓存，对两臂合并缺失集合最多做一次规范查询，随后冻结。未知与失败留在全请求分母中，不计入成功，也不改成“已知不稳定”。

每个 seed 的结果与合并 1000 请求结果同时给出；合并时 N/U 在该臂声明的整体 cohort 上计算，不直接相加两个 seed 内的 unique 数。历史 9.4/47.4 作为参考行明确标注旧协议/旧 cohort，不能代替新对照。

不在这 12 小时另训完整纯 AR、FIM、直接连续后端比较。它们属于后续论文证据；本轮结果不能声称 DLM 对所有替代架构已经胜出。

## 8. 最小必要检查和故障处理

只做与新接口/新训练直接相关的检查，不再组织大范围审计：

1. P0/B0/tokenizer/model494 与冻结身份一致，新组件关闭时恢复旧接口与调度；不以跨 GPU 长轨迹 bitwise 差异作为唯一否决条件。
2. C3FD 的公式在 rich 展开、parser、site slot、DLM 构造与修订间不变；rich 科学字段不被默认填入。
3. formula 的 BPE/语义可达性映射保留合法歧义，换行后 processor 退出；不强制改原 prompt 或公式书写顺序。
4. 每个程序都是当前物种的排列；R03 构造无混合轴越界，gamma/Z 的几何检查具备必要输入；回填不写非活动位置。
5. 新 pointer 使用原 H1A2 公式位置特征；P0 不训练；修订 checkpoint 仅在修订阶段加载，原 B0 构造与 embedding 保持不变。
6. 控制头与可选修订训练用 MP20-train，validation 用于开发；没有正式测试结果进入标签或选择。
7. 全请求身份、N/U 去重范围、官方 hull 缓存、失败/unknown 记账可追踪。

只允许保持既定科学配置的工程修复。需要改变主方法、预算、模型起点或截止时间时，报告具体原因并请求新的指示，不能在后台换路线后沿用旧方法名称。
