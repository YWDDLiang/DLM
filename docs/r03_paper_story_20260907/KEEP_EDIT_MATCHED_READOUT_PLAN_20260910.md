# 当前连续提案监督与受限接受头训练

当前证据是接受判断存在训练侧与未见来源的差异：旧E3在DEV的SUN为25、MSUN为103，相对连续KEEP为+1/−12；纯收益头最佳双指标排序结果为25/115，仍未同时提高。第一阶段回归用了5664条历史token配对，而部署对象是这次真实的连续KEEP与混合EDIT。与这一部署表示完全匹配的新提案在第一阶段仅用于评价，没有用于监督。

新阶段只把上述匹配提案中原已固定为TRAIN的来源加入监督，DEV/FINAL一条也不加入。这是新的训练阶段，不能改写前一阶段“评价提案未回流训练”的记录。目标仍为可靠的Δ新颖Stable＋Δ新颖MetaStable；明确失败为0，物理未知不作为负例，历史U不作为可移植标签。历史token样本与当前连续样本即使token视图相同，也记录不同的真实结构身份，不用token相同来强行合并相反标签。

训练池由两组组成：已核验的历史5664条配对；当前连续提案中双方有可靠收益标签且可建立token判断视图的TRAIN配对。两组总权重各为0.5，组内按来源归一，防止历史旧256的多轮样本淹没当前分布。模型特征全部来自冻结旧E3，复用已核验的缓存并逐一检查pair id、行序、文件哈希和来源；不重新生成G/F，不增加线上物理选择。

进一步冻结quality头的第一层及SiLU表征，只更新最后线性层的第3号接受输出行。其余quality输出、内容、范围和B0参数均保持原值，实际参数量在训练回执中记录。对冻结隐藏特征以TRAIN加权均值/标准差标准化，标准差下限1e-4；初始化为与原旧E3接受输出等价的线性读出。采用Adam、学习率1e-3、batch256、种子20260910，完整64遍。损失为按上述权重计算的均方收益误差，加0.1倍标准化读出权重平方和；bias不正则化。保留第8/16/32/64遍快照，接受阈值仍只选0、0.05、0.1、0.2。标准化在导出时折回原quality头末层权重和bias，不增加部署输入或外部标签。

每行实际覆盖、优化器步数、末层参数变化、冻结张量身份、标准化折回误差及重新加载后的实际1000条输出都必须核验。DEV沿用SUN和MSUN均提高的准入及原平局次序；没有任何候选通过时，FINAL继续封存。若通过，先冻结权重和阈值再打开FINAL，按同输入连续KEEP及旧E3分别比较，并按已登记的两个额外E随机流检查。
