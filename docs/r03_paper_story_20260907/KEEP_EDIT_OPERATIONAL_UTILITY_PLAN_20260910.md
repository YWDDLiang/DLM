# 最后一轮有界尝试：补足物理损伤与评价失败监督

登记于新增训练和新增候选评分之前。前一模型在原流及两个预登记流上的FINAL SUN/MSUN增量为+1/+3、0/−1、+1/+2，尚未稳定通过。其原始正式检验与失败均保留，不重置截止时间，不替换原冻结模型，不修改G/F或共同物理评价。绝对截止仍为2026-09-10 10:01:15 UTC。

诊断显示两个一般性缺口：第一，纯Δ新颖Stable＋Δ新颖MS对非新颖Stable的损伤可以给出中性目标；第二，完全排除已实际运行但未收敛的候选，会使接受判断看不到这类部署失败。前者也存在于TRAIN，后者在当前连续TRAIN提案中有对应样本。新尝试只修改TRAIN监督，不将任何DEV/FINAL标签加入训练。

新目标固定为ΔQ，其中Q=新颖Stable＋新颖MS＋0.25×(Stable＋MS)。仍不使用历史U作为可迁移单结构标签。双方可靠或明确物理失败时使用已观测标志；状态明确为not_converged时，仅将其在原固定评价预算下的可用收益记为0，不把它改标为热力学不稳定。官方参考缺失、其它物理未知及工程失败不改成负例，继续排除。所有原始物理标签保持不变，数据记录单列新增操作性失败监督。

历史5664条缓存配对根据其原始评分绑定补充Stable/MS差；恒等KEEP锚点保持零差。当前连续TRAIN配对加入上述明确未收敛的部署结果。两组仍各占0.5总权重，组内按来源归一，E来源及组成审计保留。冻结旧E3内容、范围和quality隐藏层，只更新129个接受输出参数；标准化、Adam学习率1e-3、batch256、L2系数0.1及随机种子20260910沿用上一轮。

固定训练64遍，并事前固定使用第64遍和原阈值0.05；本阶段不再搜索快照或阈值。输出为旧E3加新的quality权重补丁及明确的模型定义、训练数据和文件哈希。重新加载真实模型判断全部提案；KEEP仍返回连续原件，候选只构造一次再按模型分数选择。不得按单条物理标签选结果。

先在既有原流及repeat1/repeat2提案上比较，权重在这些新策略结果出现前冻结。模型未训练过的246个严格组成隔离来源仍单列，但这些来源的先前方法结果已经查看，因此本阶段称为探索性复用验证，不能包装成新的盲测。所有策略都完整保留分母与SUN/MSUN/Stable/MS获得和损失。

若剩余预算足够，另固定一个新E流`keep_edit_operational_fresh1`，使用同一1000个G/F输入和相同内容权重，以新抽样结果检查固定策略；仍不按这一流的结果改权重或阈值。它提供新的随机流检查，不等同于新来源的独立终测。只评价模型实际输出，可复用精确相同的已有端点标签，所有N/U在实际面板重算。

本阶段保留至少15分钟收尾空间。若不改善或时间不足，记录真实失败及未完成项；不把平均正增量或后验最好流当作稳定成功。

用户随后要求让失败输入的正常编辑得到尝试，并争取更大的SUN/MSUN提升。核对现有入口后，除了102条原已知SUN和1条没有有效结构的上游失败，897条可编辑输入已经生成合法提案，瓶颈主要是单候选供给与接受判断。为此在新增候选评分之前固定：A池使用原流E与repeat1，B池使用repeat2与新流`keep_edit_operational_fresh1`；分别由新收益头在两条候选中选择得分最高且达到0.05者，并评价A+B合并的四候选选择。所有池都返回单个最终结构，按原顺序解决分数并列，不使用候选物理标签择优。原流单候选另作控制，不再搜索策略。

对有合法token视图的失败、未收敛和低质量输入均允许候选尝试；只保护当前连续表示下已经验证的SUN。无可编辑结构的输入保留失败记录。已存的候选构造和各流实际调用次数均绑定到结果：两候选/四候选的DLM调用数逐条核验，不能超过原每请求80次上限。四候选的潜在收益必须由实际模型选择后的共同物理评分证明，不能把候选池的事后最好结果当作模型表现。

为避免旧token-SUN直通掩盖“连续当前不是SUN”的输入，新流在所有合法输入上强制构造提案，最终是否保护由连续当前的SUN决定。已生成的旧守卫版本保留，新增开放提案版本使用同一已登记的新流种子；不根据结果选择两版。既有E/重复流保持原样，新流保证其它合法状态至少有一次开放尝试。这里复用实现中的forced-proposal开关，不把DEV/FINAL生成样本加入训练。
