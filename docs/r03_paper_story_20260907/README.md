## 1. 建议锁定的科学问题

> 如何将化学约束与周期几何依赖共同融入自主晶体生成，使模型在探索多样组成时生成有效几何，并通过物理反馈提高稳定晶体的发现率？

**必须回答的 DLM 机制问题：** 几何约束需要哪些已知变量才能生效，如何让 DLM 的位置揭示与程序执行遵守这些依赖？在保持组成和非活动结构时，完整上下文可见的修订又能带来多少额外效用？几何层的历史实证见[几何有效性贡献](GEOMETRY_CONTRIBUTION.md)，模型替代与证据边界见[为什么选择 DLM](WHY_DLM.md)。

组成有效性本身是需要解决的第一部分，不能把“已经化学可行的提案”当成输入前提。这里“化学有效”按声明的组成评价器和支持范围定义，不意味着存在对应稳定结构。系统在不给定目标化学式或参考结构的情况下自主生成组成和几何；固定模型生成的组成来比较后端，是机制实验，不能替代完整 de novo 任务。稳定性采用明确的共同物理评估协议，不将其等同实验可合成性。

**已有组成端成果：** C3FD-v2.5 在两个 seed、每 seed 1000 次请求的组成生成实验中，将 `legacy_comp_valid` 从 **1724/2000 = 86.2% 提高到 2000/2000 = 100%**；每个 seed 均为 1000/1000。同期 formula 级 novel-and-unique 数由 1530 提高到 1756。这是组成生成的实证贡献，不是结构 SUN，也不是新整合系统已完成的主结果。[原始组成结果](../h1a2_to_current_review_20260907/evidence/c3fd_v25_composition2000.json)

**已有几何执行成果：** SPAD 开发队列中，精修前 Direct 联合有效率从保留顺序的 80.27% 提高到 canonical 几何执行的 99.22%，训练匹配端点为 99.80%。另一批新组成上的 B0/BC/BS 为 401/501/504 个有效结果，每臂 512 次请求；该批最终 SUN 没有同步提高。Direct 联合有效率不能随意改名为纯几何指标，且这些不是新 R03 组合的成绩。[来源、分母与归因](GEOMETRY_CONTRIBUTION.md)

**方法假说：** 将化学可达性约束落实到 LLM 的生成动作，以提高组成有效性；再让 DLM 根据 LLM 程序、在保持组成及非活动结构的条件下，读取完整可见上下文构造和修订指定几何，并用同一操作的连续物理后果训练其离散决策。已有结果支持组成端有效性提升；能否在新整合系统中同时提高稳定晶体发现产率，仍需实验检验。DLM 的贡献不能由 C3FD 的 100% 或固定 model494 的效果代替。

暂定题目：**From Chemical Validity to Physical Stability: LLM-Programmed Crystal Generation with Physical Feedback**。中文可用“从化学有效性到物理稳定性：物理反馈驱动的 LLM 编排晶体生成”。继续使用已有 SPAD 名称即可，不需要新造模块缩写。

## 2. What / Why / How

**What：** 联合生成组成、晶格和周期坐标，明确检验组成有效性及最终 Strict/Meta SUN，在相同完整生成预算下报告全部请求及失败，并保持可量化的组成覆盖与结构新颖性、唯一性。

**Why：** 自由生成的组成可能违反计数、价态等组成规则，首先损失有效探索机会；组成通过这些检查之后，仍需协调其他位点与周期晶格，才能实现合理几何。这里存在不同的决策要求：化学组成需要保持，局部几何则可能需要根据随后生成的具体环境重新判断，因此我们研究完整上下文可见的局部修订。模仿结构 token 的训练目标也未必让修订动作获得更好的物理终态。历史复盘支持这些是值得检验的问题，不证明单一根因、DLM 唯一性或某种训练目标的必要性。

**How：** 第一项机制在化学可达性支持内学习组成生成；第二项机制让 LLM 程序与 DLM 揭示/修订遵循周期几何依赖；第三项机制用连续物理反馈训练同一执行器的动作选择。三者分别负责化学有效性、几何可行性与物理稳定性。R03 的权重与安全构造提供对照和起点。

```text
明确的化学可达性支持
          ↓
LLM 自主选择组成，并预测物种级程序
          ↓
DLM 保持 N / 元素 / 计数，执行允许的构造与回填
          ↓
完整结构 → 固定连续精修 → 共同物理评价
          └── 离线评价同一修订动作的后果，训练 DLM ──┘
```

反馈首先训练 DLM 的执行分布。若实际没有更新 LLM 程序策略，不写成物理反馈已训练整个 Planner，也不称端到端联合优化。推理中的冻结连续精修与离线势能标注需分开说明。

## 3. 三个相关的大贡献

### 贡献一：化学可达性约束的学习式组成生成

将计数、价态与剩余原子预算等约束落实到可继续完成的化学动作支持，让 LLM 在该支持内学习选择组成。这直接回答“如何生成有效组成”，也直接对应 comp_valid 达到 100% 的已有实验成果。

“已有实现可复用”与“能否成为整篇论文的方法贡献”是两回事。本文保留 C3FD 组成机制作为贡献候选，写清它相对已有约束生成的具体设计和实证价值；不把普通 mask 或仅实现了旧算法当作新的通用算法，也不因它早于本轮 R03 整合而忽略已有成果。

**可以据实写的结果句：** 在已完成的两 seed、共 2000 次组成生成请求上，该机制将组成有效率从 86.2% 提高到 100%，同时 formula 级 novel-and-unique 数增加。100% 限定于该评价器、该支持范围和该实验；若要声称规则范围内的生成保证，须另外给出具体规则、完备性及终止条件的论证。

**需要的证据：** 保留上述完整请求实验与分布统计，并用对应对照区分化学支持和 LLM 学习策略的作用。组成有效率不能替代语言预训练知识归因，也不能替代最终结构稳定性。

### 贡献二：周期几何约束下的程序化 DLM 去噪

承接贡献一产生的组成，DLM 的揭示顺序与条件支持共同服从几何依赖：晶格检查需要相关角度，候选坐标的周期距离检查需要晶格与完整坐标信息。LLM 输出实际影响允许的构造或回填次序，执行器维持必要依赖。DLM 保持 N、元素和计数，并用其余已生成位点作为上下文修订指定局部几何。

R03 的重复坐标失效与 safe-axis 修复支持“约束生效依赖揭示顺序”；SPAD 的精修前 Direct 改善支持几何执行层的价值。它们不是同一组实验，不能将 80.27%→99.80% 写成 R03 上单一新改动的收益。学习程序 BP 在开发表中未超过 canonical BC，回填仅恢复部分有效性；不把几何执行的全部收益归给 LLM pointer。[详细机制与实证](GEOMETRY_CONTRIBUTION.md)

仅有固定生成顺序或“使用双向模型”的标签不足以证明贡献。AR 填空模型也能利用两侧上下文，连续生成器也能处理几何；论文应通过机制效用与相应替代对照论证 DLM 的实际价值，不声称其他模型原则上无法替代。详见[替代方案与最小证明链](WHY_DLM.md)。

R03 的原始构造是全局 lattice → X → Y → Z。移植物种程序不自动保留这个条件过程，尤其不能直接把已有 anchor-first 整体替换称为无改动继承。适配需明确保留哪些顺序、改变哪些后验上下文；构造后的回填作为单独动作记录。

**程序的证据：** 同一组成支持与同一 DLM 下比较固定程序和学习程序；若使用随机程序，预算相同。软件 trace 证明程序被执行，最终 SUN 才证明有用。标准 AR 系统比较不能证明所有 AR/infilling 模型都无法表达这种操作。

### 贡献三：物理后果指导的 DLM 生成学习

本轮利用 K4/K8 已保存的候选结构、验证标签及质量权重，进行离线 masked 修订适配；保留原模型/MP20 保持项，评估学生实际生成。不同旧候选拥有不同结构上下文，不能将它们拼成“同一状态下不同修订动作”的新反事实实验。

物理经验用于适配贡献二的修订执行器，并保持贡献一的化学组成。当前存量主标签对应原生 DLM→物理弛豫；model494 保持共同最终精修，不能因最终 SUN 在其后测量就声称训练目标已包含 model494。能量、force、SUN 分别检验，均值能量下降不保证 SUN 增长。

**需要的证据：** 同起点、同程序、同训练预算下比较有无物理反馈；同时报告教师候选的可改善空间与最终学生收益。训练中的 K 候选不能转成推理时未计成本的 best-of-K。若推理没有势能选优，可按事实说明；固定 refiner 仍然存在。

### 三项贡献的共同实证：完整发现效果与收益分解

完整 de novo 主表检验联合系统的 SUN 与成本；共同的模型生成组成、固定后端和修正前后对照，检验收益来自化学分布、结构实现还是连续精修。组成多样性和结构 N/U 分开报告，不将 cohort 级 uniqueness 写成单样本独立概率。

分阶段报告和固定分母是必要方法学，不包装为新评测算法。组成和几何执行有历史成果；新整合方法的稳定性增益仍待确认。只有完整方法对 R03 的一个差值时，只支持整法比较，不能同时声称三个机制已被独立证明。

## 6. 引言可直接采用的逻辑草稿

自主晶体发现需要同时解决化学组成有效性、周期几何可行性与物理稳定性。无约束的组成生成会产生违反化学规则的候选；单个几何 token 合法，也不能保证它们共同构成有效晶格或无严重碰撞的周期结构。进一步，即使组成与几何均通过有效性检查，结构仍可能具有较高能量。我们研究如何让这三个层次共同作用于生成决策。

方法首先让 LLM 在化学可达性支持内生成组成，已有两 seed 实验将组成有效率从 86.2% 提高到 100%。为进一步检验这些有效组成能否转化为稳定晶体，LLM 提供物种程序，DLM 保持组成并执行构造和利用完整上下文的修订；固定连续精修与物理评价为这些操作提供离线反馈。

几何生成中，约束能否被判断取决于已有上下文。我们将几何依赖落实到掩码揭示和条件取值支持，使 DLM 的位置选择服从周期结构的约束。已有开发与新组成队列都显示精修前联合有效性改善，而 SUN 未同步提升，进一步说明需要用物理反馈学习合法操作之间的稳定性差异。

这一模型选择针对具体的生成操作：化学组成选定后保持一致，局部几何则允许根据新生成的周期环境被重访。DLM 以同一 masked 条件接口承接构造和修订，LLM 程序指定更新位置，物理反馈训练更新选择。我们检验这种操作及其相对执行器的效用，不将化学有效性或连续精修的收益直接归于 DLM。

实验首先评估完整 de novo 生成的稳定、独特、新颖晶体产率及成本，再通过共同组成、程序对照和精修前后结果分解收益来源。最终结果段尚待填写；目前不写优于 R03、稳定提升、广泛化学泛化或已证明的语言知识作用。

## 7. 与剩余 12 小时实验的关系

论文的完整假说与本次能确认的结论必须分开。先取得可比的 R03 与候选主结果；如果只完成固定上游下的程序执行/物理学习比较，它回答的是所采样化学分布上的结构实现增量，不能顺带证明换用 C3FD 的上游收益。

采用知识模块的现成证据可以支持动机，但与 R03 不同接口、权重和 cohort 的历史结果不能相加成新系统主表。完整系统如果尚未适配运行，就在方法稿中标为候选设计，不能写成主实验已验证。

一轮正向主结果支持继续补全机制证据；没有正向结果时，不通过改标题或回填历史最优分数宣布科学问题已被解决。保持同一问题，可以诚实报告该机制在当前预算和支持范围内尚未带来收益。
