# 几何有效性应进入 DLM 方法主线

2026-09-07。根据用户关于既往几何有效性贡献的提醒，回读历史报告、对照定义与当前实现。本文不重新核验 C3FD 的 100% comp_valid，不运行模型或评价，不恢复历史实验。以下数字是明确来源的历史结果；未获取对应原始逐样本文件时，不声称本次逐行重算。

## 1. 可以纳入的核心贡献

建议将第二项方法贡献写成：

> **周期几何约束下的程序化 DLM 去噪：根据已知几何状态决定何时揭示变量、哪些取值可提交，并允许在保持组成和非活动结构的条件下修订局部几何。**

科学困难是：几何有效性不能由每个 token 分别合法推出，约束是否可判断又依赖生成中哪些变量已经可见。DLM 可选择非连续位置并改变揭示次序，因此需要让这种自由服从几何依赖，而不是只按 token 置信度提交。

这把 DLM 的理由具体化为“受几何约束的可编排生成与修订”。它有已有执行与有效性结果支撑；回填的 SUN 增益、学习程序优于固定程序、以及相对 AR/连续替代的优势，仍分别需要证据。

## 2. R03：约束的生效时机依赖揭示顺序

来源：[R03 原始复现报告](D:/codex_work/ai4s/diffsion_language_model_meets_diffusion/workstreams/plangraph_dlm_iclr_20260731/H1_R03_SAFE_AXIS_REPRODUCIBILITY_REPORT_V1.md)，§4、§8.1。

旧坐标检查是在候选 Z 被提交时，利用已有 X/Y 判断完整坐标是否重复。混合 X/Y/Z 的置信度揭示可能先提交 Z；此时检查缺少 X/Y，后续补齐又可能形成重复坐标。

| 实验 | 控制 | 候选 | 能支持的结论 |
|---|---:|---:|---|
| 同组 first32：原始 D1 对混合轴顺序 | 31/32 body 成功 | 14/32 body 成功；新增 18 个 duplicate 失败 | 改变顺序可以破坏几何检查的前提 |
| first32：D1 对 safe-axis | 31/32 | 31/32 | safe-axis 恢复安全性，没有新增重复坐标失败 |
| first64：D1 对 safe-axis | 61/64 | 63/64 | 有小幅 body 完成收益 |
| first256：D1 对 safe-axis | 246/256 | 248/256 | 点估计小幅提升；不能据此宣称显著的广泛性能优势 |

R03 保留 lattice→X→Y→Z 的全局依赖，再在各轴内进行分组。它首先是对新顺序引发的约束失效的修复，不能把恢复的 17/32 宣称为相对原始可靠基线的净提升。

这条证据支持的机制原则是：**掩码位置的揭示策略应与几何约束所需的信息共同设计。** 普通 AR 也可以遵守相同依赖，因此它不是 DLM 独占性的证明。

## 4. 具体几何机制与源码边界

### 4.1 晶格与坐标的可判定依赖

[`spad_program.py`](../../src/crystal_dlm/spad_program.py)中的 `canonical_predictor_position_groups` 与 `spad_predictor_position_groups` 将晶格 scalar 和 XYZ component 按依赖顺序求值。gamma 检查需要已有 alpha/beta；Z 的周期距离检查需要已有晶格和本位点 X/Y。

论文可以把完整晶格和 XYZ 描述成几何检查单元，但内部仍逐分量前向预测。不能把这写成一次模型调用同时采样整个联合几何块，也不能宣称任意中间 scalar 状态已经是完整有效晶体。

### 4.2 几何条件改变可采样取值

[`llada_generation.py`](../../src/crystal_dlm/llada_generation.py)中的 lattice-volume、duplicate-coordinate 与 PBC-distance mask 根据已知结构约束 token 支持。周期坐标 000/100 的别名概率被合并，避免把同一周期位置当成不同物理动作。

这属于生成过程中的条件支持；完整样本解析、最终有效性检查、codec round-trip 属于结果验收，不应全部合并成同一种算法创新。

**范围限制：** 当前 PBC mask 在无法获得完整晶格、X/Y 或其他完整位点时会跳过相应检查；找不到合法 Z 时会报告 `pbc_no_legal_completion`，具体调用方决定回退或处理。`periodic_geometry_ops.py` 使用有界周期像搜索，不应未经证明声称对任意病态晶格的无限周期像均严格精确。旧 B0→BC 结果不能被后续新增的严格验证逻辑重新归因。

### 4.3 可见其余结构的局部回填

[`spad_generation.py`](../../src/crystal_dlm/spad_generation.py)允许掩码指定 XYZ、保留其他位点，再按条件次序生成。程序决定回填对象，可见结构参与模型预测和几何判断。

修订接口为物理反馈提供明确的状态与动作。它与几何约束有关，但当前开发结果只显示有限的回填有效性恢复；不能将 BC 的大幅提升全算作回填收益。

### 4.4 与执行状态匹配的训练

历史训练使用 predictor、correction、random-mask 等状态类型，以适应实际构造与修订。BS 的 99.80% 支持这个完整端点具有高有效性；训练预算和状态分布同时变化时，不把它称为纯推理解码的收益。

## 5. G2 的几何关系注入怎么处理

G2 将 soft token 几何转为周期关系特征，再影响 token logits，确实是另一项几何建模工作。历史 full-epoch 对照报告 raw Direct 118/256→128/256；其后 canonical-DLM 为 143/256，而 canonical-DLM 加 G2 为 133/256，说明收益具有起点与条件依赖。[早期方法报告](../v3_scientific_audit_20260906/historical/docs/paper/SCIENTIFIC_QUESTION_AND_CONTRIBUTIONS.md)、[后续负结果](../v3_scientific_audit_20260906/historical/docs/FAILED_METHODS.md)

这可以作为几何建模的探索与边界证据。如果最终 R03 组合不运行 G2，就不将其结构图或历史收益拼入最终方法。剩余时间优先整合已经明确的几何依赖与有效性机制，不因名字中有几何就恢复一个额外分支。

## 6. 主线更新为三个相关的方法层次

1. **化学有效的组成生成：** C3FD 将科学约束落实到 LLM 的组成动作，已有 100% comp_valid 成果。
2. **几何约束的程序化 DLM 去噪：** LLM 提供程序；执行器遵守晶格/坐标依赖，几何状态约束可采样值，DLM 以可变位置和完整上下文构造/修订。已有 raw Direct 改善支持这一层的实证价值，但学习程序与回填的增量分别报告。
3. **物理后果指导的 DLM 学习：** 在上述化学和几何约束内，用连续模型与势能反馈学习哪些生成/修订动作更有利于稳定性。新系统的 SUN 增益仍待确认。

完整发现效果与机制归因是三项的实证证据，不再单独占据一个算法贡献位置。三层分别回答“组成是否有效”“几何是否可用”“物理上是否稳定”，并共同约束同一个生成过程。

建议主科学问题：

> 如何将化学约束与周期几何依赖共同融入自主晶体生成，使模型在探索多样组成时生成有效几何，并通过物理反馈提高稳定晶体的发现率？

第一层通过 C3FD 与 LLM，第二层通过受约束的 DLM 执行，第三层通过对同一执行器的物理学习，与老师要求对应。几何层使 DLM 的作用有具体机制和已有结果；它仍不等于其他架构无法做到，替代模型比较的边界继续遵循[为什么选择 DLM](WHY_DLM.md)。
