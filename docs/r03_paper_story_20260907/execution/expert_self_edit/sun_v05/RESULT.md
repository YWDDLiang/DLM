# SUN v0.5 教师候选检查：结果与收尾

结论：**不进入新训练，按用户要求归档数据并清理失败权重。** 本次64个训练来源、固定四种教师动作和两组F800噪声未提供预先登记所要求的 refined Strict SUN 正收益支持。这是教师候选空间检验，尚未训练新的DLM，也不能据此否定其他来源、动作或连续过程学习方法。

## 完整结果

下表均为 `SUN / MSUN` 计数，分母始终为64；两组F800噪声分别报告。Strict阈值为0，Meta阈值为0.1 eV/atom，保留冻结N/U口径。

原生全局动作有有限正信号：SUN从2到3，全胞候选MSUN从11到23，可得到终态能量的来源从32到62。它支持保留几何恢复/低能候选数据；该可评价数不是正式Struct_valid，也不是学生泛化能力。

固定F800后，每个非KEEP臂相对同seed的KEEP均新增0个Strict SUN，最多丢失2个。MSUN不能被这一结论概括：all_xyz的32/35高于KEEP的31/30，但Strict SUN为3/4，低于KEEP的5/5。不能用Meta的小幅上升替代本轮优先优化的Strict SUN。

## 预先登记门槛

- 两个F800种子均成立的同动作来源胜例：**0**，要求至少6。
- seed0选动作后在seed1评价，以及反向评价：都选择**64个KEEP**，净增均为**0**，要求两方向各至少4。
- 重复成立的真正局部来源胜例：**0**，要求至少2。
- 身份、来源、种子、R/F执行及重复候选一致性：**通过**。15个评分臂和640项精修均有完整回执；未知物理结果没有被用作确定负偏好。

跨噪声bootstrap输出[0,0]来自全KEEP、逐来源差值全零，属于退化的经验区间，不是总体收益被精确证明为零。

该面板全部来自current_B0_full_rich训练请求，原几何有效/无效各32个，组成互异并限制公开hull参考覆盖。2个来源不能构造native-frame教师初态，仍在所有分母中；local4有5个小结构实际为all_xyz。臂内U由于组成互异接近平凡，不能证明完整生成分布的多样性保持。

## 哪些值得保留，哪些未带来可靠收益

值得保留：确定性执行修正（已测F18/18对、R256/256输入复现一致）；next-token修复315倍位置权重偏差；可信教师与生成数据；直接按声明端点评价SUN。FIT8训练来源能达到低CE并执行部分改进，证明训练可优化。

未建立可靠收益：低训练CE向DEV稳定性的迁移、当前接受器、等价目标对齐、OLD画布、单纯增加轮数或扩大同类训练。FIT8的S开发R verified由124/128降到50/128，且接受全部17次已确认恶化。本次局部或全局稀疏教师动作也没有提供refined Strict SUN新增。已有正式编辑器raw SUN38/1200高于H1A2的27和B0的30，但refined92低于103/101，保留该回溯raw信号及实际第800步权重，不扩大结论。
