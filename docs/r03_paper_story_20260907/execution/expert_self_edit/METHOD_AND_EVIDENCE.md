# 自主晶体编辑：方法与证据记录

编辑模型与训练主体以 `61b3be191da2d3d9383277ce36204e70b1ad77ef` 为基准；正式主评测使用包含数值重复性诊断的 `a1c597f435dc62972c7604eeea3d4651c9b7059f`。raw 与 refined 均已完成。按照本轮“有一个端点 promising”的判据，raw 端达到阶段目标；refined 端 SUN/MSUN 下降，不能表述为双端全面提升。

## 方法

输入是 rich Plan 和 B0 生成的完整晶体 body。编辑器保留原子数、元素、元素顺序及 Plan，学习修改晶格和分数坐标。新增可训练参数包括 14,680,064 个 LoRA 参数及 7,798,797 个编辑模块参数；B0 的嵌入表和输出表保持原始保存值。

每个请求依次执行 G（几何或终态可靠性修复）和 S（稳定性改善）。每个任务先读取完整当前状态，预测是否编辑以及编辑范围，再通过原 DLM 的 logits 填充被遮盖的数值 token，最后预测是否接受完整提案。G 可选择 NONE、局部坐标、全部坐标或晶格与全部坐标；S 当前训练支持晶格与全部坐标，并通过状态准入与提案接受判断控制执行。局部范围来自模型预测，不能由离线的几何错误清单提供。

推理使用原状态、当前部分状态、任务、范围及剩余填充进度作为模型输入。正式策略的总预算为每请求最多 160 次前向计算，逐 token 填充，接受阈值 0.5。数值类型约束和周期端点别名合并属于词表处理。推理不调用 CHGNet、Materials Project、真值结构或外部几何筛选器；采样后的几何检查仅用于记录和评测。

## 训练与隔离

训练包含内容填充、范围及状态判断、完整提案判断。原始 teacher 目标经过实际 token 量化后重新评估；真实学生提案同时保留正例、负例和未知项。中间提案及被拒绝提案也进入离线标签台账，不能只挑最终成功样本。实际 proposal 的接受正例与能够提供内容监督的正例分别维护。

G 的监督区分原始几何恢复、弛豫终态几何恢复和终态可靠性恢复。S 的能量改善标签只来自新旧两端均可靠且能量可比的结构，阈值为 0.01 eV/atom；可靠性丢失是已观测负例。未知物理结果不当作能量负例。没有找到 teacher 不代表该状态应该停止编辑。

主评测的 reduced composition 从所有编辑训练集和开发集中排除。正式运行前递归检查每个编辑检查点的初始化来源、实际模型文件、训练与开发文件及其哈希；最终追溯至原始 B0。此约束覆盖编辑阶段，不能消除 B0 原有预训练接触。

## 物理与正式评测

共同物理流程 R 使用 CHGNet 0.3.0 权重、FIRE、FrechetCellFilter、可变晶胞、`fmax=0.1`、最多 500 步及终态能量一致性验证。原始和终态几何采用完整周期接触检查。开发集中的“R 可靠”用于诊断，不等同于 SUN 的定义。

正式主评测冻结历史 H1A2 rich Plan 1200 条请求及原始 B0 D2 body，保留原始失败项、全局顺序和每请求随机种子。编辑器可处理完整 body，包括历史建图失败的完整 body。主评测始终用 1200 作分母。

输出只报告 `comp_valid`、`Struct_valid`、SUN 和 MSUN 的 raw 与 refined 两端。refined 使用固定 model 494、800/1000 扩散步、每请求一次采样、batch size 1，在创建每请求 DataLoader iterator 前恢复历史 refiner seed。历史原始结构和 refined tensor 可以复用；物理标签按当前共同流程重新计算。

SUN/MSUN 采用冻结的 MP 热力学缓存和原有 novelty/uniqueness 判据。仅对可能贡献 SUN/MSUN 的样本计算所需 N/U，但 uniqueness 仍比较所有更早的同组成结构，包括不稳定结构。尚未解决的必要工程计算不能当作零分。合并缓存覆盖 1040 个已解析化学体系及 31 个官方未解决体系；后者保留未知标记，按既定全请求统计口径不贡献 SUN/MSUN。本轮没有新的 MP 查询。

## 已完成证据

第一阶段使用 8,568 个训练来源和 1,263 个开发来源，从原始 B0 初始化。内容监督有 5,897 个独立 G 来源、383 个独立 S 来源。6 张 A800 的有效 batch 为 24，在 1,400 次更新后早停，实际训练用时约 20.8 分钟；内容交叉熵最优的保存点为 step 800。

固定自主开发集为 259 个原始 B0 状态，全部来自训练之外。原始几何有效为 126，R 可靠为 42。step 800 的几何有效为 199、R 可靠为 43，但仅保留原可靠结构 11 个。step 1400 的几何有效为 191、R 可靠为 45，保留原可靠结构 15 个。这说明内容生成已改变结果，同时存在严重误改，不能用几何有效率替代物理质量结论。

第二阶段从 step 1400 初始化，加入完整学生提案物理反馈，并增加健康 G 状态与接受判断的训练占比。内容、检查和判断视图比例为 0.45/0.20/0.35，真实学生反馈优先比例为 0.65；检查视图内健康 G 状态比例为 0.15。LoRA 和编辑模块学习率分别为 1e-5 和 5e-5。训练与固定开发集的视图组成不同，因此不能把两者的混合 quality BCE 直接解释成接受器的泛化误差；需要自主提案验证。

第二阶段在 1,000 次更新后早停，用时 905.78 秒；含此前短测与恢复验证，累计梯度训练 2,337.01 秒（38.95 分钟）。在看主评测结果之前，依据固定开发集冻结了第二阶段 step 800，接受阈值 0.5、逐 token 填充、总预算 160 不再调整。

正式 `Struct_valid` 口径确认：开发集从 126/259 增到 187/259。独立重评的 R 可靠结果为 42→51，原可靠结构保留 39、损失 3、新可靠 12。进一步检查发现，其中 1 个“损失”和 2 个“新增”发生在 token 完全未变的结构上，属于重复 R 的数值波动；实际发生编辑的请求中，可靠性新增 10、损失 2。不能把相同结构的重复评估差异解释成编辑能量收益。

对全部 234 个已保存完整开发集事务补齐物理标签后，G 接受 130 个，其中 68 个被标为有益、62 个无益；拒绝 17 个，其中 3 个有益。S 接受 1 个有益提案，拒绝 3 个有益、40 个无益和 43 个结果不可比较的提案。该分析固定原始提案，没有重新运行 accept-all 链，也没有回流训练。这里的“有益”是一次共同 R 观测下的监督标签，不能当作已完成多次重复验证的能量增益。

主面板共 1200 请求，1186 个完整 body 可编辑，实际改变 623 个 body。G 选择 NONE 492 次、接受完整晶格及坐标提案 620 次、拒绝 74 次；S 选择 NONE 803 次、接受 3 次、拒绝 380 次。实际平均每个可编辑请求增加 39.54 次前向计算，最大 112 次。虽然模型支持局部与全部坐标模式，本次主面板实际使用的是 NONE 或完整晶格及坐标编辑。

## 数值重复性与结论范围

固定 model494 的两条历史输入重放中，单原子输入逐位复现，20 原子输入存在偏差。进一步在 6 个 GPU rank 上分别用同一个模型、相同输入和原始 seed，依次运行旧数据路径、新数据路径、旧数据路径重复：公共输入的数值与 dtype 一致，采样前后 CPU/CUDA RNG 状态一致，但旧路径自身也不逐位重复。保留了参数设备、张量布局、库版本、扩展库与实际模型源码哈希。CUDA 浮点归约是候选原因，尚未通过替换单个算子单独证实。

因此，本次保持原权重、随机数流程、800 步设置与原有数学实现，报告预先固定运行的观测结果，不按结果重抽或选结构。R 也存在少数相同输入的重复差异，已在 raw 收益归因和开发集解释中单列。当前结论来自这一冻结的 1200 条回溯面板，尚未进行多 seed 复验。

refined 的 487 个 MSUN 贡献样本另经只读邻域检查，其输入与 R 终态均没有 6 Å 截断内的孤立原子；检查没有改变原有计分或筛选样本。
