# 固定G/F的KEEP/EDIT试验：证据与结果

状态：2026-09-10北京时间约05:05，四组训练全部完成，前三组全量KL诊断已完成，固定输入的提案评测正在运行；尚未冻结开发集选择，也没有本次Stable/SUN成功结论。执行顺序、最后一次补充和后续1000条规则见[计划](EDITOR_T2T_TRIAL_PLAN_20260910.md)。

## 比较解决什么问题

固定原256条第三轮G/F输出，保持Plan、current和推理预算，比较直接KEEP、原E3、仅训练决策头，以及三个内容训练配置。固定current为Stable 32/256、SUN 28/256；原E3输出为Stable 33/256、SUN 32/256。原E3的Stable变化是获得3条、损失2条，净增1条，所以仅看最终总数会掩盖保护失败。

本次按组成分组为153个TRAIN、51个DEV、52个FINAL来源。FINAL未用于此次E更新和模型选择，但这些来源可能已进入旧RSI；这里检验的是固定G/F下编辑模块的增量效果，不能称为全新独立测试。既有流程会提供current的known-SUN标记，旧E3和所有候选沿用该保护上下文；本次不使用提案物理评分在线挑选输出，也不能把实验描述为完全不含任何已知物理状态信息的盲编辑。

内容目标取自同Plan且实际评分的历史token结构，包含先前被拒绝的好提案。历史SUN/U不作为单条目标质量标签。632个内容目标中，52个用于Stable提升、85个用于Stable恒等保护；其余为154个亚稳恒等目标和341个已验证修复目标。决策训练有3294条候选判断，来自670种不同current条件。每个current最多一个规范化动作标签和一个内容目标，避免相同条件同时被监督KEEP与EDIT。

实际可用判断覆盖153个登记TRAIN来源中的150个；其余3个没有满足可信监督条件的样本，并未移出256条比较分母。52个Stable提升目标只来自20个不同祖先，占632个内容目标的8.23%；85个Stable恒等目标来自28个祖先。重复不同current的可信目标扩充了监督，但不等于52种独立组成的提升示范。670个规范动作标签为KEEP 277、局部坐标28、全部坐标30、整胞335；EDIT标签以整胞为主，当前数据不足以单独证明可靠的局部定位能力。3294个接受判断中正例730、负例2564。绑定统计见[训练覆盖回执](receipts/EDITOR_T2T_TRAINING_COVERAGE_20260910.json)。

原学习率在第三个内容遍历开始时触发硬停，整次未完成遍历的梯度被丢弃，先前两次更新保留。触发批次的多张卡都超过阈值，随后全量T2T均值也超过0.02，因此没有证据将其解释为一个异常样本或错误的跨卡归约。只训练头的全部内容KL和CE变化精确为零，支持内容冻结实现有效。

实际覆盖核验显示，所有3294条判断在四组中都参与了8次头更新；原硬停组的每个内容目标参与2次完整更新，低学习率和关闭硬停组均为8次（4次T2T、4次M2T），没有只检查过却未参与更新的内容目标。关闭硬停组训练用时838.9秒，没有超时；552个批次中343次最大卡KL超过0.02，记录的最大批次卡均值为0.287942。该数字是训练时的批次统计，不能代替上表的全量分布均值。

原学习率模型在Stable提升与保护目标上均改善了平均CE，说明超出旧分布的变化包含朝可信目标移动的部分。低十倍学习率即使完成更多遍历，目标学习幅度仍更小。这支持检查硬停是否过早限制学习，尚不能证明关闭它会提高物理稳定性：CE只度量目标token拟合，KL只度量相对参考模型的分布变化，两者都不是Stable标签。

事前登记的最后一个对照从同一E3开始，内容学习率仍为2e-6、头学习率1e-4，软KL系数仍为1，数据、顺序、种子、8遍历及3600秒上限相同；唯一训练规则变化是关闭0.02硬停。保留全部越界记录，不增加更多训练配置。它与原学习率硬停模型的差异用于检验该停止规则；低学习率组是学习率与实际更新次数共同变化的对照，不能归因为学习率的单独因果效应。

## 选择、判定和归因

四个固定训练候选各自评估6个事前规定的决策组合：是否尊重模型KEEP，以及接受阈值0.5、0.65、0.8，共24个DEV比较。按Stable、SUN、较少Stable损失、较少编辑、较高阈值、尊重KEEP排序；相同则优先较少内容更新。冻结模型及策略后，FINAL只决定采用或回退，不能在看过FINAL后换一个候选。

最终主判断是Stable超过直接KEEP和旧E3、SUN不低于它们、原有Stable损失不超过旧E3且最多1条。旧E3还会按试验相同GPU分片和批次再执行一次，以记录数值差异；主判断同时检查原始和匹配执行的旧对照。内容候选须完整覆盖至少一次T2T和一次M2T，所有判断样本须有8遍历实际头更新；仅训练头如果获选，会明确作为头方案报告。

所有候选还会使用获选模型的共同阈值和KEEP规则比较。最终逐条报告Stable获得、保留、损失，SUN变化中S/N/U谓词的来源，以及好提案被拒绝、坏提案被接受的数量。不同内容模型也会改变头所见特征，因此共同策略下的差异说明整个内容训练分支的增量作用，不能声称纯token权重的独立效应。两种阈值若产生完全相同输出，将如实记为没有观察到阈值作用。
