# 候选最终状态概率对照：新终测打开前追加登记

原 SUN 差值双输出模型和 8 个阈值的结果完整保留。本对照由原 DEV 错误分析触发，不读取新 256 来源的编辑结果，不修改其来源选择；仍受本阶段 13:54:41 UTC 截止及 5 GPU/3 作业上限约束。

原 DEV 的具体问题包括：928 的实际 Stable 晋升候选被另一候选压过；437 同样被另一候选压过；578 的实际晋升候选已经得到最高 SUN 预测，但 MS 收益预测为 -0.1495，被候选级 MS 门槛拒绝；原本 Stable 但不新颖的 598、607、962 等来源，所有候选的 SUN 差值预测都为负。这里只引用 DEV。

两点设计局限可直接推导。其一，当前已经为 NMS 的输入，其真实 NMS 增量上界为 0；若预测接近条件期望，要求增量≥0 相当于要求候选几乎必然保持 NMS，使 SUN 晋升尝试被过严拒绝。其二，线性差值模型需要从分开的当前 Stable、Novel 特征中学习乘积及其减法，容易将当前 Stable 的损失惩罚转移到不新颖 Stable 的修复。预测候选绝对状态可去掉学习“减去当前状态”的负担。

新增一个模型，复用完全相同的 TRAIN1917 行、492 来源、冻结 E3 隐藏表示和 21 个当前状态/编辑幅度特征。两输出 logits 经 sigmoid 组合为 P(NMS)=sigmoid(z1)、P(NS)=P(NMS)×sigmoid(z0)，保证 NS 概率不高于 NMS。按两个绝对终态标签做来源均衡 BCE，保留系数0.2的同来源 SUN 排序项；KEEP 排序参照为该来源实际当前 NS 标志。未知标签与未收敛操作性零的处理沿用原数据，不增加 DEV/FINAL 监督。

Adam1e-3、64完整遍、batch256、L2=0.1、随机种子20260910及 300 个参数保持。标准化只用 TRAIN。冻结内容、范围和 quality 隐藏层。它是“终态参数化＋选择条件”的联合对照，不宣称隔离了某一个因素的单独因果效应。

DEV 固定比较 NS 概率阈值 0.05/0.1/0.2/0.3，候选内按原0.01 SUN分档、再按 NMS 概率和固定候选顺序排序；不再对“当前到候选的 MS 增量”设硬门槛。当前已验证 SUN 仍 KEEP。DEV 采用条件保持 SUN>KEEP、MSUN≥KEEP、Stable≥KEEP；并列按 MSUN、更少编辑、更严格阈值。无通过者则保留 KEEP，固定0.1模型只作为诊断输出。

原差值模型、此终态模型、旧操作性收益头在同一新256来源与同一候选池上全部报告。是否以终态模型为首选只由 DEV 决定，并在新候选物理评价前另行冻结；不按新 FINAL 结果选择赢家。原差值方法失败也不从报告中删除。最终同时提高 SUN/MSUN 仍需实际物理评价证明，且单组随机流不代表跨随机流稳定成功。
