## 2. 为什么不需要重新跑物理标注

旧能量标签绑定已生成的具体结构。把这个结构作为离线训练样本，并不会因为学生换成 R03/B0 就要求再次计算其能量。只要使用同一个物理对象、保持原协议与验证状态，就能复用已付出的采样和标注成本。

源码确认保存了这些信息：[`programmed_path_training.py`](../../src/crystal_dlm/programmed_path_training.py)按 trajectory_id 连接路径和标签；[`label_programmed_paths.py`](../../scripts/label_programmed_paths.py)保存原生/终态能量、终态结构及弛豫轨迹；[`build_programmed_path_teacher.py`](../../src/scripts/build_programmed_path_teacher.py)记录完整条件、采集轮次、参考 checkpoint 和验证协议。

需要做的只是文件索引、标签连接、旧 token 到 B0 token 的对应以及普通 masked 训练视图。保持物理结构不变，不生成新坐标、候选晶体或弛豫轨迹。数据优先在其原存储位置使用，避免为少量适配搬运全部大轨迹文件。

## 3. 为什么旧训练命令不能原封不动运行

[`train_programmed_path_policy.py`](../../src/scripts/train_programmed_path_policy.py)要求训练 checkpoint 与 teacher 的采集参考一致，原加载器还要求训练过的 periodic state conditioner。它拟合的是旧执行路径和旧支持变换。

R03 的 rich 条件、初始轴顺序和新增局部修订不等于旧 SPAD 全路径。不能删除这些一致性检查、把 checkpoint 改成 B0 就声称继续了同一个物理目标。

本轮明确改用：**已有物理质量权重指导的离线 masked 修订适配。** 利用旧候选的实际最终原生结构及质量权重训练 B0 副本，原 B0 继续负责构造。它是知识迁移，不是新 R03 策略的在线反馈或原完整路径目标的逐字复现。

## 4. 具体的轻量复用方案

1. 读取 K8 已验收的 teacher/path/label manifest；K4 consistent v2 只补充 K8 缺少可用监督的条件组。保留采集轮次、原 group_id 与 source_row_idx；同组成的总体训练权重归一，避免两轮叠加放大重复组成。若两轮条件字段不同，不按组成名字强行拼成同一个原 teacher 分组。
2. 沿用已有正权重、验证状态及失效标记。只将能保持物理身份、满足目标表示和几何支持的原生 body 作为 masked 目标；保存不兼容条目及原因，不重新抽样补齐。单候选组只能提供质量样本拟合，不能声称包含组内偏好比较。
3. 取最终原生 body 的 XYZ block 做普通掩码训练视图，使用已有物理权重加权拟合；不把多个完整结构拼成“同一状态下不同局部动作”，也不把全路径能量差分配成已知的某一步因果收益。
4. 原记录有完整、语义兼容的条件时保持它；只有 Compact 条件时不伪造 H1A2 rich 字段。必要时，修订阶段统一采用双方都可提供的固定组成、当前几何与活动位置视图，G/P 使用同一修订输入协议。原 H1A2 rich 生成及 R03 初始构造不变。
5. 从原 B0 副本训练仅用于修订的 LoRA，建议 LR `1e-6`、最多 256 更新，加原 B0/MP20 保持项；base、embedding 与原始构造 checkpoint 冻结。只做一轮，不追加数据采集。
6. 与未做物理适配的 G 在相同开发请求和相同修订接口下比较，采用规则沿用总计划。未通过则保留 G，所有数据复用与训练结果仍交付。

新的离线 loss 只声称拟合旧物理经验加权后的 masked 条件分布。旧 teacher 的双目标可行性、KL 约束和旧策略回报保证不会因此自动转移到 R03；最终收益看新模型生成结果。

## 5. model494 反馈的准确范围

K4/K8 的主 teacher 是原生结构及 CHGNet 物理弛豫的反馈，主要使用 e0−eR 与 eR，不包含 model494/tau800。因此本轮默认写“复用既有势能反馈的离线学习”，model494 保持为共同最终精修。

如果已有**训练用途**、同一结构身份和同协议的 tau800 标签，可单独登记复用；没有就不补跑，也不把原生标签改称 tau800 标签。现有 `231_refine_state_programmed_paths.sbatch` 是 evaluation 用途的 256 请求通道，这类结果只能评价，不能当训练数据。

## 6. 时间与范围变化

删除总计划中“128 个新训练组成、K4 新候选、最多1024次教师终态、重新物理标注”的步骤。相应时段仅做存量数据兼容视图、短训和开发比较，不重新构造物理训练池。

已有 K4 报告的训练阶段约十余分钟，昂贵部分主要在先前采样和标注；这提供省时依据，但不作为新 B0 适配必然同速的保证。仍遵守方法冻结和主结果截止时间。
