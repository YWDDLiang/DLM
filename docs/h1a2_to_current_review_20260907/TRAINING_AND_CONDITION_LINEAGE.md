## 4. 四个最重要的断点

1. **teacher rich Plan参考与de novo条件不是同一任务。** R5-C conditional的Plan来自真实结构；H1-A2在部署时要自己抽联合化学/结构属性，且composition固定后DLM不能纠正错误formula。更晚的minimal路线主动移除了lattice/SG/volume信息。缺口不能全部归为DLM“没多训几轮”。H1-A2 epoch3 marginal TVD/loss改善却未改善下游，后来sufficient CE与SGTC再次表明teacher拟合指标不是稳定性充分目标。[S2][S4][S5]

2. **重构确实重置了权重，但没有证据证明这是长期停滞的唯一原因。** 38703、39282、raw-v1、V2分别从原始LLaDA开始，旧R5-C、grounding或K4/K8能力不会自动叠加。38703和V2的同期记录明确注明用户授权；不能把它们写成擅自丢权重。39282还有具体修复动机：重排前的C3FD_NATIVE_PLAN_V2、teacher-native/Compact数据，与该代推理hard prefill的site顺序一致比例仅4069/27136 train、1296/9047 val。入口87训练的是Aug31的c3fd_native_teacher_sft_v1_20260831，canonicalize脚本也明确断言teacher-native及C3FD_NATIVE_PLAN_V2；**这不是本次逐行重放May29 R5-C所得比例，不足以断言May29/H1-A2必有同一错配。** 现有证据没有在相同数据、条件、预算下比较fresh与warm-start，因此“reset造成退化”仍是待验证因果假说。尤其grounding和SGTC本身未证明稳定性贡献，不能把它们当作已获得又被丢失的成果。[S3][S5][S6][S7][S9]

3. **V2提高了部署接口一致性，却改变了soft条件的监督语义。** 保存的FROZEN_CONDITIONING_AUDIT确认：所有27136条train clean answer和composition不变；24558条换成predicted_direct，2578条teacher_soft_fallback。预测部分17945/24558条至少一个soft字段与原teacher不一致，仅6613条三个字段全一致。val为8147条预测、900条fallback，其中11条原因是unsupported_frozen_stratum。这些来源没有被删掉，coverage是真实的；但当soft/program仅从C及确定性化学witness抽样，而目标Y仍固定为原结构，训练便不再严格要求“指定SG/volume对应同名结构”。模型可能学会依赖C或弱化soft。该改变是有理由的分布匹配尝试，不能同时称作已证明的结构意图控制。V3沿用同一份条件数据。[S13][S10]

4. **更换目标多次，但有判别力的物理teacher覆盖仍有限。** 普通CE、反事实Plan margin、strict-positive筛样、contact-order、K4/K8双目标路径和V3连续denoising是不同监督任务。K4有效物理teacher仅覆盖526/1024组成，273组有多候选；其经验重加权相对均匀分布总变差仅2.5613%，收益还集中在少数组。K8扩至662组，并没有变成完整MP20的能量训练。V2/V3又明确回到原MP20 teacher，不读取K4/K8数据。增加完整source-view数确实增加训练量，但不能说此前学到的能量偏好在后续继续累积，也不能把teacher双目标可行性当成student或SUN改善。[S8][S9][S10]
