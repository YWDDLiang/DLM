# C³FD-v2.3 CPU audit — terminal engineering NO-GO

Date: 2026-08-28

The constructive Pauling-witness state was scientifically well defined, but
its per-charge recursive cache was still running at the frozen 120-second
limit and had reached roughly 1.27 GB RSS. It was terminated, no GPU job was
submitted, and no gate was relaxed.

The separately preregistered v2.4 candidate preserves the witness and action
set while replacing individual charge states with integer bitset convolution.
